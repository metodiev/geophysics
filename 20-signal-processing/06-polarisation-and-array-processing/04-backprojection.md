# Back-Projection Imaging of Rupture

## Learning objectives

By the end of this lesson you will be able to:

1. **Define** the back-projection imaging condition as a beamformer in source
   space, and **derive** why its peak locates a radiating point in space and
   time.
2. **Recover** a rupture velocity from the slope of the image ridge and
   **compare** it with the model value.
3. **Measure** the array point-spread function in space and time and **explain**
   why it sets the resolution of the image.
4. **Quantify** the location bias produced by a wrong travel-time model.
5. **Explain** the ambiguity between a propagating rupture and a spatially
   extended simultaneous source, and **demonstrate** it.
6. **State** the conditions under which back-projection is informative at all.

All models and data in this module are **SYNTHETIC**. The fault, rupture,
records and noise are generated by the accompanying demonstration; no real
earthquake, station or waveform is used and no number is quoted from a published
measurement.

## 1. Intuition: beamforming into the source, not into the sky

An array measures arrival-time differences and converts them into a direction.
Back-projection keeps the same machinery but changes the question. Instead of
asking "which slowness best explains the records?", it asks "which point on a
known fault radiated at which moment?" For each candidate point and moment, it
computes the arrival time that point would produce at each sensor, delays the
records accordingly, and adds them. The candidate is right when all the delays
line up and the sum is large.

The result is a two-dimensional image: fault position along strike against
origin time. A rupture that propagates is a **diagonal ridge** in that image, and
the slope of the ridge is the reciprocal of the rupture velocity. It is a
remarkably direct measurement — no waveform inversion, no source model, no
Green's functions beyond a travel-time table — and its limitations are equally
direct, which is why this lesson measures them carefully.

## 2. Precise definitions

### 2.1 Geometry and travel times

Let $\xi$ parameterise a point on the fault (here: along-strike distance in km)
and $i$ index the sensors. Given a travel-time model $T(\xi, i)$ — the time for a
signal from $\xi$ to reach sensor $i$ — the arrival of energy radiated at point
$\xi$ at origin time $\tau$ is

$$t_{\text{arr}}(\xi,\tau,i) = \tau + T(\xi,i).$$

### 2.2 The imaging condition

Record $x_i(t)$ at each sensor. Define the **back-projection image**

$$\boxed{\;I(\xi,\tau) = \sum_{i=1}^{N} x_i\!\left(\tau + T(\xi,i)\right).\;}$$

This is a sum over sensors of the data sampled along the travel-time curve of the
candidate source. It is exactly a delay-and-sum beamformer
([20-06-02 §2.2](02-beamforming.md)), with the steering parameter being the
source location instead of the slowness.

### 2.3 The ridge and the rupture front

Suppose the true source is a point at $\xi_0$ radiating a pulse $g(t)$ at origin
time $\tau_0$, so $x_i(t) = g(t - \tau_0 - T(\xi_0,i))$. Substituting,

$$I(\xi,\tau) = \sum_i g\!\left(\tau - \tau_0 + T(\xi,i) - T(\xi_0,i)\right).$$

Every term is maximal simultaneously when $\xi = \xi_0$ and $\tau = \tau_0$ —
the peak locates the point exactly, with the array gain $N$ and no bias. For a
rupture that propagates with velocity $v_r$ from $\xi = 0$ at $t = 0$, each
point $\xi_0$ radiates at $\tau_0(\xi_0) = \xi_0/v_r$, so the peaks trace a line

$$\tau(\xi) = \frac{\xi}{v_r}
\qquad\Longrightarrow\qquad
\boxed{\;\frac{\mathrm{d}\tau}{\mathrm{d}\xi} = \frac{1}{v_r} .\;}$$

The demonstration's model has $v_r = 2.50\ \mathrm{km\,s^{-1}}$, so the predicted
slope is $0.4000\ \mathrm{s\,km^{-1}}$; the measured ridge slope is exactly
$0.4000$ and the recovered velocity is $2.500\ \mathrm{km\,s^{-1}}$, an error of
$0.0\%$ on noise-free-quality data.

## 3. Worked example: the synthetic experiment

The demonstration builds a line fault of length $L = 40$ km at depth
$H = 30$ km, with $c = 6\ \mathrm{km\,s^{-1}}$, a source pulse of half-width
$\sigma = 0.2$ s, and a surface line array of 20 stations spanning
$\pm20$ km. Each fault point at 1-km spacing radiates the pulse when the rupture
front reaches it, so the sub-events are spaced $1/2.5 = 0.40\ \mathrm{s}$ apart in
time — **wider than $\sigma$**, which is the condition that makes them
individually distinguishable.

| quantity | value |
|---|---|
| fault and depth | $0$–$40$ km, $30$ km deep |
| rupture velocity | $2.50\ \mathrm{km\,s^{-1}}$ |
| rupture duration | $16.0$ s |
| array | 20 stations, $\pm20$ km (aperture 40 km) |
| sampling | 50 Hz, 26 s |
| noise | 5% of signal rms |
| first / last arrival at centre | 5.00 s / 24.33 s |
| measured ridge slope | $0.4000\ \mathrm{s\,km^{-1}}$ |
| recovered $v_r$ | $2.500\ \mathrm{km\,s^{-1}}$ (error 0.0%) |

The measured ridge passes through $\tau = 2.40$ s at $\xi = 6$ km, $7.20$ s at
$\xi = 18$ km and $14.40$ s at $\xi = 36$ km — $2.40 = 6/2.5$, $7.20 = 18/2.5$,
$14.40 = 36/2.5$ — to the printed precision. **A back-projection image measures
the time at which each place radiated.** Everything else it is claimed to measure
is an inference from that.

## 4. Worked example: resolution is the array point-spread function

Image a single point source and you obtain the array's **point-spread function**
(PSF) in the $(\xi,\tau)$ plane. The demonstration measures a PSF of half-width

- **3.0 km along strike**, and
- **0.40 s in origin time**

for the 40-km aperture. The image of any real rupture is the true
space–time source distribution convolved with this PSF, so features smaller than
the PSF are not resolvable regardless of the data quality.

The PSF width is set by the aperture, exactly as the slowness resolution of
[20-06-03](03-array-design.md) is. Measuring it at five apertures (20 stations
each):

| aperture | 10 km | 20 km | 40 km | 60 km | 80 km |
|---|---|---|---|---|---|
| PSF half-width | 13 km | 6 km | 3 km | 2 km | 2 km |

Halving the aperture roughly doubles the width, and the improvement saturates at
2 km once the width approaches the 1-km fault grid — a numerical floor, not a
physical one. **An aperture is chosen for the smallest feature the study must
resolve, and the fault grid is then chosen finer than the PSF.**

## 5. Worked example: the velocity model is an assumption

Back-projection does not solve for the travel-time model; it presumes one. A
point sub-event at $\xi = 20$ km firing at $\tau = 8.0$ s, imaged with four
assumed speeds, gives:

| assumed $c$ | imaged $\xi$ | imaged $\tau$ | bias in $\xi$ |
|---|---|---|---|
| 6.0 km s$^{-1}$ (true) | 20 km | 8.00 s | $+0$ km |
| 5.7 km s$^{-1}$ ($-5\%$) | 19 km | 7.75 s | $-1$ km |
| 5.4 km s$^{-1}$ ($-10\%$) | 18 km | 7.50 s | $-2$ km |
| 6.3 km s$^{-1}$ ($+5\%$) | 21 km | 8.20 s | $+1$ km |

A 5% velocity error moves the apparent location by 1 km at 20 km distance, and a
10% error by 2 km. The bias scales with the distance from the part of the fault
the array constrains best, so a location quoted from back-projection is a
location **conditional on the travel-time model**, and its uncertainty from that
source alone is several kilometres. Two further consequences follow.

- A biased model shifts *all* the sub-events coherently, so the recovered
  **rupture velocity** is much more robust than the absolute positions: a
  uniform model bias changes the mapping between $\xi$ and $\tau$ only weakly.
  This is why back-projection is used for rupture kinematics, not for absolute
  hypocentres.
- Improving the model is worth more than improving the array for absolute
  location, but not for resolution.

## 6. Worked example: the ambiguity that limits the method

Now make the source radiate the same pulse from the **whole fault
simultaneously** at $t = 0$, with no propagation delay. The demonstration images
it and finds a 50% extent along strike of $39.0$ km, against the 3.0-km
point-spread function of a true point source. Without a propagation delay to
exploit, the image is essentially the fault extent convolved with the array
response — the two situations (a propagating rupture and a synchronously
radiating extended source) can produce similar images, and the method alone
cannot always separate them.

This is the honest limit of the technique. It is why back-projection results are
reported with the independent constraints that break the ambiguity: the
radiated energy, the slip distribution from a finite-fault inversion, the
directivity from a second array at a different azimuth, or a comparison against
a rupture model. A back-projection image is a **space–time map of high-frequency
radiation**, not a slip distribution, and the two are not the same quantity.

## 7. Assumptions and regime of validity

1. **A known fault geometry.** The image is only defined on the grid supplied;
   radiation from outside it is folded into the nearest grid node.
2. **A travel-time model.** Positions are conditional on it, as measured in
   Section 5.
3. **A locally plane, known propagation path.** The method is normally applied
   at teleseismic distance with a 1-D reference model; three-dimensional
   structure of a few per cent is a systematic location error.
4. **Impulsive, distinguishable sub-events.** The pulse width $\sigma$ must be
   shorter than the time between successive rupture-front positions, i.e.
   $\sigma < \Delta\xi/v_r$. With a continuous, smoothly slipping rupture the
   records are an overlapping smear and the ridge is not recoverable — the
   demonstration fails outright for $\sigma = 0.3$ s with 0.40-s spacing.
5. **Coherent signal across the array.** The array gain $N$ is available only
   for the coherent part of the wavefield; incoherent noise gains nothing.
6. **Adequate frequency content.** The method uses the high-frequency band
   because that is where the radiation is impulsive; the low-frequency
   moment release is invisible to it.

## 8. Units and dimensional analysis

| Quantity | Symbol | Unit | Check |
|---|---|---|---|
| fault coordinate | $\xi$ | km | |
| origin time | $\tau$ | s | |
| travel time | $T(\xi,i)$ | s | km / (km s$^{-1}$) |
| ridge slope | $\mathrm{d}\tau/\mathrm{d}\xi$ | $\mathrm{s\,km^{-1}}$ | $1/v_r$ |
| rupture velocity | $v_r$ | $\mathrm{km\,s^{-1}}$ | reciprocal of the slope |
| image | $I$ | signal unit | a sum of amplitudes |

The slope of the ridge and the inverse rupture velocity have the same unit;
inverting the slope is justified only if the ridge is a straight line, which is
itself a physical statement about the rupture (constant velocity) that should be
checked rather than assumed.

## 12. Common pitfalls

1. **Reading a slip distribution from a back-projection image.** It images
   radiation, not slip; they differ in band and in weighting.
2. **Quoting an absolute location without the velocity model.** The bias is
   measured in Section 5 and is kilometres.
3. **Ignoring the point-spread function.** Features smaller than the PSF are not
   evidence of anything.
4. **Using too long a source pulse.** The method needs sub-events separated in
   time; a smoothly slipping rupture is unrecoverable.
5. **Assuming the ridge must be straight.** A curved ridge is a physical result
   (variable rupture velocity), not a failure — but it must be tested against
   the resolution.
