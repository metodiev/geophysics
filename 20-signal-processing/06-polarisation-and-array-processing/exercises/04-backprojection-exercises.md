# Exercises — 20-06-04 Back-Projection Imaging of Rupture

Attempt these before reading the
[solutions](./04-backprojection-solutions.md). The lesson is
[04 Back-Projection](../04-backprojection.md). All models are **SYNTHETIC**
teaching values.

## ★ Foundational

**★1.** A back-projection ridge passes through $\tau = 6\ \mathrm{s}$ at
$\xi = 15\ \mathrm{km}$ and $\tau = 14\ \mathrm{s}$ at $\xi = 35\ \mathrm{km}$.
Compute the rupture velocity and state the assumption about the rupture that the
answer uses.

**★2.** An image has a point-spread function of half-width 4 km and shows a
single bright spot 3 km wide. State the strongest defensible claim about the
source.

**★3.** Two processing centres image the same synthetic event with different
arrays and report initiation points 3 km apart. Give two candidate explanations
and one additional observation that would separate them.

## ★★ Applied

**★★4.** A back-projection study images a rupture with an 80-km aperture and finds
a 2-km point-spread function. It wants to resolve sub-events 1 km apart. State
whether the study can succeed, and compute the aperture that would be required if
the point-spread function scales as $1/L$.

**★★5.** A fault is imaged on a 2-km grid. The rupture velocity is
$3.0\ \mathrm{km\,s^{-1}}$. State the maximum source-pulse half-width $\sigma$ for
the sub-events to remain individually radiated, and say what happens if the real
pulse is twice that.

**★★6.** The lesson measured a 5% velocity-model error moving the image by 1 km at
20 km from the array centre. Estimate the bias at 60 km for the same 5% error,
stating the assumption your estimate uses and how you would test it.

## ★★★ Research-oriented

**★★★7.** Design a back-projection experiment for a 100-km rupture, stating the
array aperture, the sampling rate, the fault grid, the travel-time model
requirements and the claims the design supports. Also state one claim it does
**not** support. A design that could not be executed is a failed answer.

**★★★8.** The lesson shows that a whole-fault simultaneous source and a
propagating rupture can produce similar images. Design a test that distinguishes
them using the same array, and state the observable difference the test relies on.
