# Beamforming, Slowness Estimation and f-k Analysis

## Learning objectives

By the end of this lesson you will be able to:

1. **Define** the slowness vector of a plane wave and **derive** the delay-and-sum
   (Bartlett) beamformer from the plane-wave model.
2. **Derive** the analytic array response of a uniform linear array and show it
   is a $\operatorname{sinc}$-squared pattern in slowness.
3. **Predict** the main-lobe null position $1/(fL)$, **measure** it from data,
   and explain why resolution depends on frequency times aperture.
4. **Derive** the grating-lobe positions $1/(fd)$ from spatial aliasing, and
   **measure** them.
5. **Derive** the array gain $N$ against incoherent noise and **measure** it
   against a single sensor.
6. **State** the Rayleigh slowness resolution and **measure** the separation at
   which two waves merge.

All models and data in this module are **SYNTHETIC**. The sensors, the plane
waves and the noise are generated by the accompanying demonstration; no real
array, event or waveform is used and no number is quoted from a published
measurement.

## 1. Intuition: an array is a spatial filter

A single station measures the time history at one point. An array measures the
*same* wavefront at several points, and the differences between the recordings
carry the direction the wave came from. If the wave is locally planar, the
time difference between two sensors is a linear function of their separation:
$\Delta t = \mathbf{s}\cdot\Delta\mathbf{r}$, where $\mathbf{s}$ is the
**slowness vector** — the reciprocal of the apparent velocity, directed along
the propagation direction in the horizontal plane.

Estimation is then straightforward. Guess a slowness, delay each trace by the
amount that guess predicts, add them, and look at the result. For the correct
guess all the signal energy adds coherently and the sum is large; for a wrong
guess the arrivals do not line up and the sum is small. Scanning slowness and
plotting the energy gives the **array response**; its peak is the estimate. The
same construction in the frequency domain is **f–k analysis**, and the array's
ability to separate one slowness from another is its resolution.

## 2. Precise definitions

### 2.1 Plane wave and slowness

A time-harmonic plane wave of frequency $f$ with slowness vector $\mathbf{s}$
satisfies

$$u(\mathbf{r},t) = w\!\left(t - \mathbf{s}\cdot\mathbf{r}\right),
\qquad |\mathbf{s}| = \frac{1}{c_{\text{app}}} .$$

With $\mathbf{r}$ in km and $t$ in s, $|\mathbf{s}|$ is in $\mathrm{s\,km^{-1}}$.
For a vertically incident body wave $|\mathbf{s}| = 0$; for a teleseismic P,
$|\mathbf{s}|$ is of order $0.05\text{–}0.08\ \mathrm{s\,km^{-1}}$; for a
surface wave crossing an array, it is much larger.

### 2.2 The delay-and-sum beamformer

For $N$ sensors at positions $\mathbf{r}_j$, the stacked (Bartlett) beam trace
at test slowness $\mathbf{s}$ is

$$b(t;\mathbf{s}) = \frac{1}{N}\sum_{j=1}^{N} u(\mathbf{r}_j, t + \mathbf{s}\cdot\mathbf{r}_j).$$

In the frequency domain the same operation is a weighted sum with a phase ramp,

$$B(f;\mathbf{s}) = \frac{1}{N}\sum_{j} U_j(f)\, e^{+i2\pi f\, \mathbf{s}\cdot\mathbf{r}_j},$$

and the **beam power** used to scan is

$$P(\mathbf{s}) = \sum_{f} \left|B(f;\mathbf{s})\right|^{2}.$$

### 2.3 The array response

For a single monochromatic plane wave of slowness $\mathbf{s}_0$, amplitude $W$,
substituting $U_j = W e^{-i2\pi f \mathbf{s}_0\cdot\mathbf{r}_j}$ gives

$$B(f;\mathbf{s}) = \frac{W}{N}\sum_j e^{+i2\pi f(\mathbf{s}-\mathbf{s}_0)
\cdot\mathbf{r}_j},$$

so the normalised array response (beampattern) is

$$B_{\text{norm}}(\mathbf{s}-\mathbf{s}_0) =
\left|\frac{1}{N}\sum_j e^{i2\pi f(\mathbf{s}-\mathbf{s}_0)\cdot\mathbf{r}_j}
\right|^{2}.$$

It is a function of the *difference* of slownesses only, it has unit value at
$\mathbf{s} = \mathbf{s}_0$, and it is the object every array-design question in
[03 Array Design](03-array-design.md) is about.

## 3. Derivations

### 3.1 The uniform linear array response

Place $N$ sensors at $x_j = jd$, $j = 0,\dots,N-1$, along one axis, and let the
horizontal slowness difference be $\Delta s = s - s_0$. With
$\theta = 2\pi f\,\Delta s\,d$,

$$\sum_{j=0}^{N-1} e^{ij\theta} = \frac{1-e^{iN\theta}}{1-e^{i\theta}},
\qquad
\left|\sum_{j=0}^{N-1} e^{ij\theta}\right|^{2}
= \frac{\sin^{2}(N\theta/2)}{\sin^{2}(\theta/2)},$$

so

$$\boxed{\;B_{\text{norm}}(\Delta s)
= \frac{1}{N^{2}}\,\frac{\sin^{2}\!\left(N\pi f\,\Delta s\,d\right)}
{\sin^{2}\!\left(\pi f\,\Delta s\,d\right)} .\;}$$

This is a $\operatorname{sinc}$-squared pattern in the variable
$f\,\Delta s\,d$. Three consequences follow immediately.

- **Peak** at $\Delta s = 0$ with value $1$.
- **First null** where $N\pi f \Delta s d = \pi$, i.e.
  $\Delta s = 1/(N f d) = 1/(fL)$ with $L = Nd$ the aperture. The demonstration
  predicts $1/(5\times18) = 0.0111\ \mathrm{s\,km^{-1}}$ and measures a
  half-power width of $0.0080\ \mathrm{s\,km^{-1}}$ — narrower than the first
  null, as it must be.
- **Periodicity** in $\Delta s$ with period $1/(fd)$ (Section 3.3).

The demonstration computes the response from synthetic data and compares it with
the analytic form on a monochromatic wave, finding a maximum difference of
$9.881\times10^{-15}$ over the whole slowness scan: the data beamformer and the
closed form are the same object, and the "measured array response" below is a
data product that can be trusted.

### 3.2 Resolution in slowness

The null-to-null width of the main lobe is $2/(fL)$. The classical
**Rayleigh criterion** puts the resolution limit at about half that, i.e.

$$\Delta s_{\min} \approx \frac{1}{fL} .$$

Two consequences that are easy to state and hard to remember under pressure:
resolution improves **linearly with frequency** and **linearly with aperture**,
and it does **not** improve with the number of sensors at fixed aperture. Adding
sensors to a fixed-length array improves the *sidelobe* level and the ability to
suppress coherent noise, not the resolution.

### 3.3 Grating lobes and spatial aliasing

The pattern of Section 3.1 is a function of $\theta = 2\pi f \Delta s d$, which
is periodic with period $2\pi$. Therefore $\Delta s = m/(fd)$ reproduces the
main lobe exactly, for every integer $m$:

$$\boxed{\;\Delta s_{\text{grating}} = \frac{m}{f d}
\quad\Longleftrightarrow\quad
\text{phase shift between adjacent sensors} = 2\pi m .\;}$$

The cause is **spatial aliasing**, and it is worth stating in the sampling
language: with spacing $d$, any two slownesses differing by $1/(fd)$ produce
*exactly the same samples* at the sensors, so no algorithm can tell them apart
from that array. The aliasing-free range is

$$|\Delta s| < \frac{1}{2fd},$$

the slowness-domain Nyquist limit, exactly analogous to $f < 1/(2\Delta t)$ in
time. The demonstration measures the grating lobes directly: for the 10-sensor
array with $d = 2\ \mathrm{km}$ and $f = 5\ \mathrm{Hz}$ the predicted offset is
$1/(5\times2) = 0.1000\ \mathrm{s\,km^{-1}}$ and the measured secondary peaks are
at $-0.091$ and $+0.091$. A second array with the **same aperture** but
$d = 0.5\ \mathrm{km}$ has predicted offset $0.4\ \mathrm{s\,km^{-1}}$, outside
the scanned range, and shows no grating lobe. **Spacing controls aliasing;
aperture controls resolution.** Confusing the two is the commonest array-design
error.

### 3.4 Array gain

Let the signal be the same plane wave at every sensor (amplitude $A$) and the
noise be independent between sensors with variance $\sigma_n^{2}$. The beam sum
gives signal $\frac{1}{N}\sum_j A = A$ and noise variance

$$\operatorname{Var}\!\left(\frac{1}{N}\sum_j n_j\right)
= \frac{\sigma_n^{2}}{N},$$

so the power signal-to-noise ratio improves by

$$\boxed{\;G = \frac{A^{2}/(\sigma_n^{2}/N)}{A^{2}/\sigma_n^{2}} = N
\quad\Longleftrightarrow\quad 10\log_{10}N\ \text{dB} .\;}$$

This is the array analogue of the stacking gain of
[20-05-04](../05-noise-and-random-signals/04-noise-reduction.md), and it carries the same condition: the noise
must be **incoherent** between sensors. The demonstration measures a per-sensor
SNR of $-15.10\ \mathrm{dB}$, a beam SNR of $-5.14\ \mathrm{dB}$, a beam-noise
rms of $0.1562$ against a single sensor's $0.4922$ (a ratio of $3.151 \approx
\sqrt{10}$), and an array gain of $9.97\ \mathrm{dB}$ against the predicted
$10\log_{10}10 = 10.00\ \mathrm{dB}$.

## 4. Worked example: resolving two plane waves

Two equal plane waves with slownesses $0.100$ and $0.100 + \Delta s$
$\mathrm{s\,km^{-1}}$ impinge on the 10-sensor, 18-km array. The demonstration
scans slowness and asks whether the beam power shows two peaks:

| separation $\Delta s$ | measured peak separation | valley/peak | verdict |
|---|---|---|---|
| 0.030 | 0.0304 | 0.038 | resolved |
| 0.015 | 0.0158 | 0.097 | resolved |
| 0.008 | 0.0096 | 0.556 | partly resolved |
| 0.004 | — | 1.000 | merged |

The Rayleigh limit is $1/(fL) = 0.0111\ \mathrm{s\,km^{-1}}$. Separations above
it are cleanly resolved; at $0.008$ the two peaks remain just distinguishable
(valley at 56% of the peaks); at $0.004$ there is a single peak. **No processing
recovers the two slownesses once they are merged**, because the information is
not in the data — the array cannot distinguish them from one wave of intermediate
slowness. This is the honest statement of array resolution, and it is the
slowness-domain twin of the two-tone merging measured in
[20-05-02](../05-noise-and-random-signals/02-autocorrelation-spectra.md).

## 5. Worked example: the f–k plane and its pitfalls

Scanning $P(\mathbf{s})$ over a two-dimensional grid of slownesses is the
classical **f–k (frequency–wavenumber) analysis**. The wavenumber is
$\mathbf{k} = f\mathbf{s}$, so a line of constant apparent velocity $c_{\text{app}}$
is the line $|\mathbf{k}| = f/c_{\text{app}}$ through the origin, and a plane
wave appears as a ridge along such a line. The same three facts recur:

1. the peak position gives the slowness, to within the resolution $1/(fL)$;
2. the ridge repeats every $1/(fd)$ in slowness if the spacing is too coarse;
3. the contrast between ridge and background is the array gain.

A one-dimensional array is blind to the component of slowness along the array
line's perpendicular: it measures $\mathbf{s}\cdot\hat{\mathbf{x}}$ only. A
two-dimensional layout (an L-shape, a circle, or an irregular grid) is needed to
resolve the full slowness vector, and that is the design question of
[03 Array Design](03-array-design.md).

## 6. Assumptions and regime of validity

1. **A locally plane wave.** The beamformer assumes $\mathbf{s}$ is constant
   across the array. Curved wavefronts (a nearby source) and lateral
   heterogeneity violate it, and the peak then broadens or splits.
2. **Known sensor positions to better than a fraction of a wavelength.** A
   position error $\delta x$ costs a phase error $2\pi f s \delta x$; at high
   frequency this is the dominant error, not the noise.
3. **A single dominant arrival per slowness.** Two waves at the same slowness
   are indistinguishable; several arrivals at different slownesses appear as
   several peaks but interact when closer than the resolution.
4. **Incoherent noise for the gain formula.** The $10\log_{10}N$ gain holds for
   independent sensor noise; coherent noise (a pressure signal on all sensors, a
   common-mode instrument artefact) gains nothing.
5. **Slowness must not exceed the phase velocity of the medium** for a real
   arrival; slownesses near or below that limit correspond to evanescent or
   non-physical waves and are artefacts of the scan.

## 7. Units and dimensional analysis

| Quantity | Symbol | Unit | Check |
|---|---|---|---|
| slowness | $\mathbf{s}$ | $\mathrm{s\,km^{-1}}$ | 1 / (km s$^{-1}$) |
| position | $\mathbf{r}_j$ | km | |
| delay | $\mathbf{s}\cdot\mathbf{r}$ | s | ✓ |
| phase | $2\pi f\,\mathbf{s}\cdot\mathbf{r}$ | rad | Hz × s/km × km = dimensionless |
| wavenumber | $\mathbf{k}=f\mathbf{s}$ | $\mathrm{km^{-1}}$ | Hz × s/km |
| resolution | $1/(fL)$ | $\mathrm{s\,km^{-1}}$ | 1/(Hz km) |
| grating offset | $1/(fd)$ | $\mathrm{s\,km^{-1}}$ | 1/(Hz km) |

Every phase in this lesson is dimensionless, and the only way to get a
dimensional result is to omit or double a $\mathrm{km}$ in a sensor position — a
very common bug when positions are in metres and slowness in
$\mathrm{s\,km^{-1}}$.

## 11. Common pitfalls

1. **Confusing spacing with aperture.** Spacing sets aliasing, aperture sets
   resolution; an array can be fine on one and hopeless on the other.
2. **Assuming the array gain applies to coherent noise.** Only the incoherent
   part gains.
3. **Reading a slowness peak without its resolution.** The peak is a ridge of
   width $1/(fL)$, not a line.
4. **Ignoring sensor-position errors.** At high frequency they dominate, and
   they mimic a slowness bias.
5. **Reporting a slowness from a one-dimensional array as a direction.** One
   component of the slowness vector is all it measures.
