# Module 20-06 — Polarisation and Array Processing

**Stages:** research · **Prerequisites:** modules 20-01, 20-02 and 20-05;
linear algebra.

This module is about extracting direction and motion from geometry. A single
three-component sensor measures a *shape* — a hodogram — from which the ray
direction and the phase of an arrival can be read. An array of sensors measures
the *same* wavefront at several places, and the differences between them give the
slowness. Both are inverse problems in miniature: the measurement is a set of
projections, and the answer is a direction that must be reconstructed with a
stated resolution and a stated ambiguity.

All models and data in this module are **SYNTHETIC**. Every wave packet, sensor
layout and record is generated by the module's demonstrations from a fixed seed;
no real array, earthquake or waveform is used, and no number is quoted from a
published measurement.

The module deliberately measures the *limits*. A polarisation azimuth is an axis,
not a direction, so it is defined only modulo $180^\circ$; a circular particle
motion has no azimuth at all. An array's resolution is set by aperture and
frequency, never by the number of sensors; its aliasing-free range is set by
spacing; and once two waves merge below the resolution limit the information is
gone. The final lesson uses these ingredients in back-projection imaging of a
rupture, where the array's point-spread function and the assumed velocity model —
not the data quality — set what can be claimed.

## Learning objectives

By the end of this module you will be able to:

1. **Build** the three-component covariance matrix of a wave packet and
   **interpret** its eigenvalues as rectilinearity and planarity.
2. **State** the $180^\circ$ ambiguity of a polarisation azimuth and compute the
   azimuth uncertainty from a signal-to-noise ratio.
3. **Derive** the delay-and-sum beamformer and the array response of a uniform
   linear array.
4. **Predict** the main-lobe null at $1/(fL)$, the grating lobes at $1/(fd)$ and
   the array gain $N$, and **verify** each against a measured response.
5. **Design** an array for a stated slowness resolution, aliasing-free range and
   sidelobe level, and **state** which requirement must be relaxed when they
   conflict.
6. **Interpret** a back-projection image: recover a rupture velocity from the
   ridge slope and state the resolution and model limits of the result.
7. **Distinguish** what an imaging method measures from what is commonly claimed
   for it.

## Common pitfalls across this module

1. **Reading an azimuth as a direction.** Linear polarisation gives an axis,
   defined modulo $180^\circ$.
2. **Confusing spacing with aperture.** Spacing controls aliasing; aperture
   controls resolution; more sensors at the same aperture do neither.
3. **Reporting a single irregular layout.** Sidelobe levels scatter; report the
   ensemble.
4. **Applying the array gain to coherent noise.** Only the incoherent part gains.
5. **Quoting a back-projection location without its velocity model.** The bias is
   measured in lesson 04 and is kilometres.
