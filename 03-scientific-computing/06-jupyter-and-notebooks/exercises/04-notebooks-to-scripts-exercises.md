# Exercises — 03-06-04 Converting Notebooks to Scripts, Tests and Reports

> Solutions, with the measured line counts, exit codes and byte sizes, are in
> [`04-notebooks-to-scripts-solutions.md`](./04-notebooks-to-scripts-solutions.md).

---

## ★ Foundational

**★1.** List three things a `PythonExporter` conversion preserves and three it
discards.

**★2.** Why is the exported script's stdout supposed to match the notebook's
stored output? State the condition that must hold.

**★3.** A converted script starts with
`get_ipython().run_line_magic('matplotlib', 'inline')`. Explain the error it raises
and give two ways to fix the notebook.

**★4.** Which `nbconvert --to` target produces a file that a non-Python reader can
open, and what does it contain that the script does not?

**★5.** What is the percent (`# %%`) format, and why does it run as a script?

---

## ★★ Applied

**★★6.** Convert a notebook of your own to a script with both
`PythonExporter(exclude_input_prompt=True)` and the CLI, and report the line
counts. Explain any difference.

**★★7.** Take a notebook with a shell escape (`!ls`) and a timing magic, export
it, run the export, and report the exit code and the first error line. Then fix it
properly and report the new exit code.

**★★8.** Convert a notebook containing a plot into (a) HTML and (b) a script, and
report the size of each. Explain why the script is smaller and what the script's
reader loses.

**★★9.** Write a `pytest` test asserting the Bouguer slab value to a relative
tolerance of 1e-12, and a second asserting that the ratio of two densities equals
the ratio of the two corrections. Report the tolerance you had to use and why it
is not zero.

**★★10.** Write a one-line change to the demonstration notebook that would make
"execute and diff the stdout" fail to detect a real error, and explain why the
diff cannot see it.

---

## ★★★ Research-oriented

**★★★11.** Design a conversion pipeline and measure it. For a notebook of your
choice produce: a percent-format module, a `pytest` module that imports it, and an
HTML report — all generated by one script. Report the number of steps, the files
produced with their sizes, and which step needed hand editing. Then state what
would break if the notebook were edited by someone who did not know about the
pipeline.

**★★★12.** Measure the fidelity of a round trip. Take a notebook, export it to a
script, and convert the script back into a notebook with
`nbformat.v4.new_notebook` splitting on `# %%` markers. Compare the two notebooks
cell by cell: report the number of cells, the number whose source is identical,
and the cells that differ with the reason. Conclude with what the round trip can
and cannot preserve.
