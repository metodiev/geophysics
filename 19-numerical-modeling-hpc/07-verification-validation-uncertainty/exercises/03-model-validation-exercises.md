# Exercises — 19-07-03 Model Validation Against Observations

Attempt these before reading the
[solutions](./03-model-validation-solutions.md). The lesson is
[03 Model Validation](../03-model-validation.md). All data are **SYNTHETIC**.

## ★ Foundational

**★1.** Three validation stations give residuals $+0.010$, $-0.020$ and
$+0.030$ mGal with a stated uncertainty $\sigma = 0.010$ mGal. Compute the reduced
chi-square and say whether the model is rejected by the band
$1 \pm 3\sqrt{2/N}$.

**★2.** Compute the $3\sigma$ band on the reduced chi-square for $N = 25$
validation data, and for $N = 4$. State how many models the wider band will admit.

**★3.** In one paragraph, explain why a validation in which the "observations" were
generated by the same model can never test that model, and name the one thing such
a test does establish.

## ★★ Applied

**★★4.** A buried body produces an anomaly over stations from 100 m to 3 km. You
must decide between (i) a point-mass model and (ii) a finite cylinder, using a
single survey. State the split you would use, the reason, and the quantity you
would report to make the test legible to a reader.

**★★5.** A model predicts $g = C\,a\,s(\mathbf{x})$ where $C$ is a physical
constant, $a$ is fitted by least squares from the same data, and
$s$ is the shape. The code uses $C' = (1+\eta)C$. Show that the residuals are
identical for any $\eta$, and compute how much the fitted $a$ moves for
$\eta = 0.02$.

**★★6.** A model of a compact body gives $\chi^{2}_{\text{red}} = 15$ against $N =
19$ validation data whose uncertainty you believe. State the two possible
explanations, and give the diagnostic that distinguishes them.

## ★★★ Research-oriented

**★★★7.** You suspect that a gravity model of a compact body carries a $2$ per cent
error in the gravitational constant, but the density contrast is fitted from your
own data. Specify the independent measurement that would detect the error, state
the precision it would need, and explain why a second, more precise version of the
*same* gravity survey cannot help.

**★★★8.** A regional bullet model (a simple, low-parameter climate model) is
described in a report as "validated against the instrumental temperature record".
Write the two questions you would ask first, and state what kind of statement the
authors are entitled to make about an *unused* observable.
