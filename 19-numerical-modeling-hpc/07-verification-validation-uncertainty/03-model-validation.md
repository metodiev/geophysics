# Model Validation Against Observations

## Learning objectives

By the end of this lesson you will be able to:

1. **State** the difference between verification and validation in terms of the
   reference each one compares against, and **name** the class of error each one
   cannot detect.
2. **Construct** a calibration/validation split for a stated model class, and
   **explain** why fitting and testing on the same data cannot validate anything.
3. **Compute** a reduced chi-square from data, model and stated uncertainty, and
   **interpret** it against a band derived from the sampling distribution.
4. **Demonstrate** that a model class can be admitted by the calibration data and
   rejected by held-out data, and **state** what that outcome means.
5. **Show** that validation is insensitive to an error in any constant that
   multiplies a freely fitted parameter, by exhibiting the exact degeneracy.
6. **Report** a validation result with the data split, the parameter freedom, the
   noise model and the admitted set of models, not a single best fit.

All models and data in this module are **SYNTHETIC**. The "observations" below are
generated by the lesson's demonstration from a chosen buried body plus Gaussian
noise. No real survey, station or anomaly is used, and no number is a measurement
of the Earth.

## 1. Intuition: verification is against mathematics, validation is against the world

Verification ([01](01-code-verification.md)) compares the code with an exact
solution of *the same equations*. It can be completed by one person and a
workstation, and its result is permanent: the code's order of accuracy does not
depend on which data set you later apply it to.

Validation is different in three ways that matter.

- **The reference is independent.** A validation compares the model's prediction
  with data the model did not generate. There is no way to do this alone: someone
  must measure something.
- **It is a prediction test, not a fit.** Fitting a model to data and reporting the
  misfit measures the fit; it does not test the model. Only predictions of data
  that were *withheld* from the fit test the model.
- **It is conditional.** What "valid" means depends on the stated parameter
  freedom, the stated noise model, and the class of models compared. A model that
  passes today's validation may fail tomorrow's better data, and that is the
  normal state of affairs, not a mistake.

The concrete asymmetry is that **validation cannot detect a compensated error.**
If a model has a two per cent error in a constant that multiplies a parameter you
fit freely from the same data, the fit absorbs the error exactly and the validity
test passes. The demonstration below exhibits that degeneracy to machine
precision, and it is the single most important honest limitation in this lesson.

There is a second asymmetry, subtler and more useful. **Calibration and validation
data do different jobs, and a data set can be excellent for one and useless for
the other.** Far-field anomaly data constrain a body's total mass and almost
nothing else; near-field data constrain its shape. A model class fitted to the far
field can be accepted by the far field, and then rejected by the near field. This
is not a paradox: it is what non-uniqueness looks like from the outside, and it is
why validation splits must be designed, not merely chosen.

## 2. Definitions

**Calibration (training) set.** Data used to determine the model's free
parameters.

**Validation set.** Data withheld from the calibration, used only to score
predictions. It must be plausible that the physics which produced the validation
data is the same physics the model describes.

**Misfit.** A scalar summarising the residual $r_i = d_i - g_i$ weighted by the
data uncertainty $\sigma_i$. The standard choice is

$$\chi^{2}_{\text{red}} = \frac{1}{N}\sum_{i=1}^{N}
\left(\frac{d_i - g_i}{\sigma_i}\right)^{2},$$

the reduced (per-data) chi-square. With $P$ fitted parameters and Gaussian
errors, $\chi^{2}_{\text{red}}$ has mean $1$ and standard deviation
$\sqrt{2/(N-P)}$ exactly in the linear-Gaussian case; the band
$1 \pm 3\sqrt{2/N}$ used below is a stated convention built on that fact.

**Admitted set.** All models, within the stated parameter freedom, whose misfit
lies inside the acceptance band. Reporting the admitted set rather than a best fit
is what turns a fit into an inference
([18-01-03 Null Space, Non-Uniqueness and Equivalence Classes](../../18-inverse-problems/01-inverse-problem-foundations/03-null-space.md)).

**Model-form (structural) error.** The part of the discrepancy that no choice of
parameters can remove, because the equations or the parameterisation are wrong.
It is exactly what validation tests, and the only error type that verification is
blind to.

## 3. The validation protocol

1. **State the question.** "Which of these model classes is consistent with these
   data?" is answerable; "is the Earth this body?" is not.
2. **State the parameter freedom.** Which parameters are fitted, with what bounds?
   A model with more freedom is easier to fit and harder to validate.
3. **State the noise model.** $\sigma_i$ must be a real uncertainty, not a tuning
   knob. Reducing $\sigma$ to make a misfit look acceptable inflates every
   $\chi^{2}$-based conclusion.
4. **Split the data in a way that matters.** A random split tests interpolation; a
   split by spatial range, by time, or by observable tests extrapolation. Say which
   you did and why.
5. **Fit and score separately.** Fit on the calibration set; score on the
   validation set; never re-fit after seeing the validation score.
6. **Report the admitted set**, not only the best fit, and state which extra
   observable would most reduce it.

## 4. Derivation: the degeneracy between a constant and a fitted parameter

Let a model predict $g = G\,a\,s(\mathbf{x})$, where $G$ is a physical constant,
$a$ a parameter fitted linearly from the data, and $s$ a shape function that
depends only on the body's geometry. The fitted amplitude from the calibration set
is

$$\hat{a} = \frac{\sum_i s_i\,d_i}{\sum_i s_i^{2}} \quad\text{(uniform } \sigma).$$

Now suppose the code is wrong: it uses $G' = (1+\eta)G$ with $\eta \neq 0$. The
prediction is $g' = G'a's = (1+\eta)G a' s$, and the fitted amplitude becomes

$$\hat{a}' = \frac{\sum_i s_i\,d_i}{G(1+\eta)\sum_i s_i^{2}}
= \frac{\hat{a}}{1+\eta},$$

Then the prediction itself is

$$g' = G(1+\eta)\hat{a}' s = G(1+\eta)\frac{\hat{a}}{1+\eta}s = G\hat{a}s = g,$$

**identically**. The residuals are unchanged at every data point, so
$\chi^{2}_{\text{red}}$ is unchanged, and no test on these data can detect $\eta$.
The fitted parameter moves by $-100\eta/(1+\eta)$ per cent — in the demonstration,
$-1.96$ per cent for $\eta = 0.02$ — and that movement is the only trace the error
leaves.

The consequence is general and worth stating in one line: **a validity test
measures the model class plus the noise model; it does not measure the
constants.** Those must come from an independent measurement, from a different
observable, or from a laboratory or a standard.

## 5. Measured evidence

The demonstration `code/model_validation_demo.py` (~0.6 s) runs the whole protocol
on a synthetic problem.

### 5.1 Verification first: the quadrature code against an exact solution

The gravity of a uniform sphere has the exact closed form obtained from the shell
theorem; a three-dimensional Gauss-Legendre quadrature of the volume integral is
an *independent* implementation of the same equations. For a sphere of radius
$120$ m centred at $300$ m depth with $\Delta\rho = 400$ kg m$^{-3}$, the maximum
relative difference between the two at $x = 200, 400, 800$ m is

| quadrature nodes per axis | max relative difference |
|---:|---:|
| 6 | $7.23\times10^{-5}$ |
| 10 | $2.01\times10^{-7}$ |
| 14 | $7.17\times10^{-10}$ |
| 20 | $1.84\times10^{-14}$ |

That is a verification statement: the quadrature solves the stated equations.
It says nothing about whether those equations model the Earth, and it is the
prerequisite for trusting the forward model used below.

### 5.2 The synthetic problem

A vertical cylinder, radius $100$ m, extending from $50$ m to $400$ m depth, with
$\Delta\rho = 300$ kg m$^{-3}$; $41$ stations from $-800$ m to $800$ m at $40$ m
spacing; noise $\sigma = 0.010$ mGal on a peak anomaly of $0.6123$ mGal, i.e.
$1.6$ per cent of peak. Two splits are used:

- **split A:** calibration $|x| \ge 400$ m (22 data), validation $|x| < 400$ m
  (19 data);
- **split B:** calibration $|x| \ge 200$ m (32 data), validation $|x| < 200$ m
  (9 data).

### 5.3 Split A: 22 calibration data, 19 validation data

Acceptance band $1 \pm 0.97$ (3 sigma, $N = 19$).

| model | parameters | $\chi^{2}_{\text{red}}$ calibration | $\chi^{2}_{\text{red}}$ validation |
|---|---:|---:|---:|
| point mass | 2 | 1.10 | **303.12** |
| cylinder, best fit on the grid | 3 | 1.10 | **15.08** |
| cylinder, true parameters | 3 | 1.10 | **1.61** |

The point-mass fit gives a depth of $276$ m and a mass of $2.884\times10^{9}$ kg
against the cylinder's true mass $3.299\times10^{9}$ kg. The best-fit cylinder on
the grid is radius $110$ m, bottom $440$ m, $\Delta\rho = 223$ kg m$^{-3}$ against
the truth $100$ m, $400$ m, $300$ kg m$^{-3}$.

All $120$ grid models are admitted by the calibration data, and the reason is
visible in the parameters: their radius spans the whole grid ($60$–$150$ m) and
their bottom depth the whole range ($200$–$640$ m), but their **mass spans only
$3.19\times10^{9}$ to $4.54\times10^{9}$ kg — a factor of $1.4$**. The far field
determines the mass; it does not determine the shape. Their validation
$\chi^{2}_{\text{red}}$ spans $1.61$ to $3721$: the held-out data do what the
calibration data could not.

Split B behaves the same way with the near field withheld: the band is
$1 \pm 1.41$; the point mass scores $1.18$ on calibration and $53.60$ on
validation, the grid-best cylinder $1.16$ and $43.16$, the true-parameter cylinder
$1.18$ and $1.59$. Here $102$ of $120$ grid models are admitted by calibration,
with masses spanning $2.74\times10^{9}$ to $4.02\times10^{9}$ kg (a factor of
$1.5$).

### 5.4 The self-validation trap

Generating "observations" from the fitted cylinder model and then scoring that
same model on them gives $\chi^{2}_{\text{red}} = 0.75$ — a pass. Scoring the
*true* body's field against those same data gives $16.4$ — the truth is rejected
by data that were never generated from it. The test is real, but it measures
consistency with the assumed noise model, not validity.

### 5.5 The degeneracy, measured

Using split B and the true geometry, with the density contrast fitted linearly:

| code | fitted $\Delta\rho$ (kg m$^{-3}$) | $\chi^{2}_{\text{red}}$ |
|---|---:|---:|
| correct constant $G$ | 305.72 | 1.182625 |
| $G$ multiplied by $1.02$ | 299.72 | 1.182625 |

The maximum absolute difference between the two residual vectors is
$1.4\times10^{-17}$ mGal — machine precision. The fitted density moves by
$-1.96$ per cent, which is exactly the constant error. There is no test on these
data that can distinguish the two codes.

## 6. Assumptions and regime of validity

1. **The noise model is right.** Every $\chi^{2}$ conclusion is conditional on the
   stated $\sigma_i$. Real data have systematic errors that are not Gaussian,
   not independent and not known to the analyst; when they dominate, the
   interpretation must change from "inconsistent at $5\sigma$" to "inconsistent
   with the assumed error model".
2. **The calibration and validation data sample the same system.** If the target
   changes between the two sets, a validation failure says nothing about the model.
3. **The parameterisation is fixed before the fit.** Choosing the grid, the model
   class or the split *after* seeing the validation score invalidates the score.
4. **The band is a convention.** $3\sqrt{2/N}$ is a stated choice; with small $N$
   it is wide, and a wide band accepts more models. Report $N$ with the band.
5. **Held-out prediction tests the class, not the constants.** Section 4 shows this
   exactly; no amount of good fitting detects a compensated constant error.
6. **What validation does not give.** It does not provide a probability that the
   model is true. Model selection and evidence are separate machinery
   ([18-05-07 Bayesian Evidence and Model Selection](../../18-inverse-problems/05-bayesian-inversion/07-evidence-and-model-selection.md)).

## 7. Units and dimensional analysis

| Quantity | Symbol | Unit | Check |
|---|---|---|---|
| observed and modelled data | $d_i, g_i$ | mGal or SI | must be the same quantity, same convention |
| data uncertainty | $\sigma_i$ | same as the data | a ratio, so $\chi^{2}$ is dimensionless |
| reduced chi-square | $\chi^{2}_{\text{red}}$ | dimensionless | mean 1 under the null |
| noise band | $3\sqrt{2/N}$ | dimensionless | scales as $N^{-1/2}$ |
| density contrast | $\Delta\rho$ | kg m$^{-3}$ | the fitted amplitude of the gravity model |

The most common unit blunder in validation is a mismatch of *conventions* rather
than units: observed gravity referred to a datum vs modelled absolute gravity,
anomalies with different reduction steps, or a magnetic anomaly with a different
ambient field removal. Such a mismatch appears as a coherent bias in the residuals
and is easily mistaken for model error.

## 8. Worked examples

### Example 1 — chi-square by hand

One validation station has $d = 0.0842$ mGal, $g = 0.0791$ mGal and
$\sigma = 0.010$ mGal. Then $(d-g)/\sigma = 0.0051/0.010 = 0.51$ and the
contribution to $\chi^{2}$ is $0.51^{2} = 0.26$. With $19$ such stations and an
average contribution of $303/19 = 16.0$ for the point-mass model, every station
individually is about $4\sigma$ — a systemic failure, not a single outlier.

### Example 2 — why a point mass fails at close range, from the fitted parameters

The demonstration's point-mass fit to split A gives depth $z_0 = 276$ m and
amplitude $1.925\times10^{4}$ mGal m$^{2}$ (equivalently a mass of
$2.884\times10^{9}$ kg, since the amplitude is $10^{5}Gm$). Its prediction at the
profile centre is

$$g_{\text{PM}}(0) = \text{amp}\times\frac{z_0}{z_0^{3}}
= \frac{1.925\times10^{4}}{276^{2}} = 0.253\ \text{mGal},$$

against $0.612$ mGal observed: a shortfall of $59$ per cent. The reason is
geometric. At the surface above its centre, the cylinder's mass is concentrated
closer to the station than the centre of mass used by the point-mass model, so the
true field is larger. Fitting the far field cannot see this, because at long range
both bodies reduce to the same monopole.

### Example 3 — the degeneracy to machine precision

Take the true shape $s$ in mGal per unit $\Delta\rho$. Code A predicts
$g = G\Delta\rho s$; code B predicts $g = (1.02G)\Delta\rho s$. Fitting
$\Delta\rho$ by least squares, code B's fitted amplitude is
$\hat{\Delta\rho}_B = \hat{\Delta\rho}_A/1.02 = 305.72/1.02 = 299.72$
kg m$^{-3}$, which is what the demonstration prints. Then
$g_B = 1.02G \times 299.72\,s = G \times 305.72\,s = g_A$ identically, so the
residuals agree to the rounding of the arithmetic: measured
$1.4\times10^{-17}$ mGal.

### Example 4 — writing the validation result

> Model class: vertical cylinder, radius and bottom depth fitted on a grid, density
> contrast fitted linearly. Calibration: $|x| \ge 400$ m, 22 data.
> Validation: $|x| < 400$ m, 19 data, $\sigma = 0.010$ mGal (synthetic).
> Band $1 \pm 0.97$. Point mass: $\chi^{2}_{\text{red}} = 303$. Cylinder,
> grid-best: $15.1$; cylinder, true parameters: $1.61$. The admitted set from the
> calibration data has $120$ members with masses within a factor of $1.4$ but radii
> spanning the whole grid. Conclusion: the data determine the mass; the shape
> requires the near field, which is withheld in split A and rejects the whole
> admitted set. No claim is made about the true body beyond the admitted set.

Note what the report contains: the split, the parameter freedom, the noise model,
the band, the scores and the admitted set. Each of those is a lever a reader could
change and re-run.

## Common pitfalls

1. **Reporting a fit as a validation.** The calibration misfit is a measure of the
   fit; only withheld prediction tests the model.
2. **Validating against your own model's output.** The demonstration measures
   $\chi^{2}_{\text{red}} = 0.75$ for that trap, against $16.4$ for the truth it
   rejects.
3. **Tuning $\sigma$ until the model passes.** The noise model is an input, not a
   free parameter; changing it changes every conclusion.
4. **Selecting the split after seeing the score.** That converts the validation set
   into a second calibration set with extra steps.
5. **Believing a passing validation certifies the constants.** Section 4 shows the
   exact degeneracy; only an independent measurement fixes a constant.
6. **Reporting a best fit without the admitted set.** Non-uniqueness is the usual
   case, and the admitted set is the honest answer.
