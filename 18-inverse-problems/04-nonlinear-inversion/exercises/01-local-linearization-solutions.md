# Solutions — Local Linearisation, Jacobians and Iteration

**1.1** $J = -a\,e^{-a u_0} = -a\,d(u_0)$. With $a = 0.5$ and $u_0 = 1$: $d(u_0) = e^{-0.5} = 0.6065$, so $J = -0.5(0.6065) = -0.30327$. The residual is $r = d - d^{\text{obs}} = 0$ if $0.6065$ is the datum, so no step is taken; a residual of $0.05$ gives $\Delta = -(J^{\mathsf T}J)^{-1}J^{\mathsf T}r = -(-0.30327)(0.05)/(0.30327^2) = 0.05/0.30327 = 0.1649$. Units: $a$ in 1/km, $u$ in km.

**1.2** $e^{-a(u+\delta)} = e^{-au}\left[1 - a\delta + \tfrac12 a^2\delta^2 - \tfrac16 a^3\delta^3\right]$. The linear-model prediction keeps two terms, so the residual error is $e^{-au}\left[\tfrac12 a^2\delta^2 - \dots\right] = O(\delta^2)$. A Gauss–Newton step solves the linearised problem exactly, so the remaining error is quadratic in the step: order 2. The demo measured the order as 2 on exact data (final errors $10^{-3}$ to $10^{-12}$ over successive iterations).

**1.3** Because the linearised model misfit has no linear term left after the step: the next error is proportional to the square of the previous one, which is the definition of quadratic convergence. Order 1 appears only when the data are noisy, because then the residual is dominated by noise that the iteration cannot reduce.

**2.1** $J^{\mathsf T}J = \begin{pmatrix}2 & 2.1\\ 2.1 & 2.21\end{pmatrix}$, determinant $= 4.42 - 4.41 = 0.01$, so $(J^{\mathsf T}J)^{-1} = 100\begin{pmatrix}2.21 & -2.1\\ -2.1 & 2\end{pmatrix}$. $J^{\mathsf T}r = (0.2 - 0.1,\ 0.2 - 0.11)^{\mathsf T} = (0.1, 0.09)^{\mathsf T}$. Then $\Delta = -100(0.221 - 0.189,\ -0.21 + 0.18)^{\mathsf T} = -100(0.032, -0.03)^{\mathsf T} = (-3.2, 3.0)^{\mathsf T}$. The near-singular normal matrix (determinant 0.01) is why the step is large; the condition number is $4.21/0.00012 \approx 3.5\times10^{4}$.

**2.2** The truncation error of a central difference is $O(h^2)$ and the representation error is $O(\varepsilon/h)$ with $\varepsilon \approx 10^{-16}$. The minimum is at $h \approx \varepsilon^{1/3} \approx 6\times10^{-6}$. The lesson's demo measured the best $h = 10^{-6}$ for its operator, consistent with that balance; the exact value depends on the curvature of the forward operator.

**2.3** Each column of $J$ needs one perturbed forward evaluation, plus the unperturbed one, so $p+1$. If the Jacobian is sparse, several parameters can be perturbed simultaneously provided no two of them affect the same datum; this is the graph-colouring trick, and it requires knowing the sparsity pattern (the forward operator's dependency structure) in advance. With $q$ colours the cost becomes $q+1$.

**3.1** Truncation: fix exact data and vary the step of the linearisation, measuring the residual after the first step against $\delta$; the null hypothesis is that the residual scales like $\delta^{2}$. Noise amplification: fix the linearisation and vary $\sigma$ with $\sigma \to 0$, measuring the final model error; the null hypothesis is that it scales linearly in $\sigma$ and does not fall below the noise floor. If the measured order degrades with noise while the truncation test still gives order 2, the two effects are separated.

**3.2** A reparameterisation is a smooth invertible map $\phi$ with $u = \phi(\theta)$. The Jacobian transforms like $J \to J\,\partial\phi/\partial\theta$, so $J^{\mathsf T}J$ is unchanged by orthogonal $\partial\phi/\partial\theta$ and its spectrum is otherwise reweighted; the sequence of iterates changes, but the point satisfying $\nabla f = 0$ (and hence a converged minimum, if the map is a bijection) does not. Expect a different iteration count and the same converged model, with the same objective to within the stopping tolerance.

**3.3** A convergence order is a property of the algorithm applied to the *declared* objective with the *actual* forward operator. Field data do not have a known $u^{\text{true}}$, so the error being measured in the lesson cannot be formed; only the residual, which is not the error, is available. Two measured facts from the lesson make this concrete: the exact-data order was 2 while the noisy iteration was linear, and the linearisation error floor was set by the noise level rather than by the step size. Neither can be quoted for a field dataset without a synthetic twin and an explicit statement that the twin is a model.
