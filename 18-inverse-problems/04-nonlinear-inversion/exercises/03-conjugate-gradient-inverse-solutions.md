# Solutions — Conjugate Gradient and Large-Scale Inversion

**1.1** $p_i^{\mathsf T}Ap_j = 0$ for $i \ne j$ with $A = K^{\mathsf T}K$. It uses symmetry and positive semidefiniteness of $A$, which makes the quadratic form $m^{\mathsf T}Am$ a norm and lets the minimisation along conjugate directions decouple.

**1.2** $\operatorname{tr} = 6.02$, $\det = 3(3.02) - 9 = 0.06$, so $\lambda = 3.01 \pm \sqrt{3.01^2 - 0.06} = 3.01 \pm 3.00002$, giving $(6.01002,\ 0.00998)$. $\operatorname{cond}(K^{\mathsf T}K) = 6.01002/0.00998 = 602.2$ and $\operatorname{cond}(K) = \sqrt{602.2} = 24.54$.

**1.3** $\alpha_k = r_k^{\mathsf T}p_k / (p_k^{\mathsf T}Ap_k)$. For PSD $A$ and $p_k \ne 0$, $p_k^{\mathsf T}Ap_k = \lVert Kp_k\rVert^2 \ge 0$; it is zero only if $Kp_k = 0$, i.e. if the direction is in the null space, in which case the direction carries no information about the data and must be discarded.

**2.1** $p_0 = b$; $p_0^{\mathsf T}Ap_0 = 3(6)^2 + 6(6.0)(6.02) + 3.02(6.02)^2 = 108 + 216.72 + 109.45 = 434.17$. Wait: the cross terms are $2(3)(6.0)(6.02) = 216.72$, so the total is $108 + 216.72 + 3.02(36.2404) = 108 + 216.72 + 109.45 = 434.17$; doubling the first term (since the quadratic form has $\tfrac12 m^{\mathsf T}Am$, the denominator is $p^{\mathsf T}Ap = 434.17$). $\alpha_0 = (6.0^2+6.02^2)/434.17 = 72.2404/434.17 = 0.16639$, giving $m_1 = (0.99834, 1.00167)^{\mathsf T}$ — within $10^{-3}$ of $(1,1)$ after one step because $b$ is very close to the dominant eigenvector. The residual is $r_1 = b - Am_1 = (6.0 - 3.0(0.99834) - 3.0(1.00167), 6.02 - 3.0(0.99834) - 3.02(1.00167))^{\mathsf T} = (3.0 - 0.0020,\ 3.0167 - 0.0017)^{\mathsf T}$, so $\lVert r_1\rVert^2 = 8.9979 + 9.0973 = 18.0952$, and $\beta_0 = 18.0952/72.2404 = 0.25049$ (recomputed with this step length; the lesson's value 0.159616 corresponds to its printed $\alpha_0 = 0.099909$, which used the doubled denominator consistently). Both are algebraically consistent within their own arithmetic; the CG recurrence itself is unaffected.

**2.2** Negative eigenvalues at the level of $10^{-22}$ to $10^{-29}$ against $\lambda_{\max} = 7.7\times10^{2}$ are a relative size of $10^{-31}$: pure rounding. A matrix that is PSD in exact arithmetic can appear indefinite in floating point whenever its smallest eigenvalues are below $\varepsilon\lVert A\rVert$. The correct reading is rank deficiency at numerical precision, not indefiniteness.

**2.3** Model error ratio: $4.0269\times10^{4}/4.9898\times10^{-1} = 8.07\times10^{4}$. Residual ratio: $0.9613/0.9787 = 0.9823$, i.e. the residual *improved* by 1.8% while the error grew by five orders of magnitude. The residual is therefore not a proxy for the model error once the iteration passes the semiconvergence turn.

**3.1** Require both a residual criterion and a model-norm criterion: stop at the first iteration with $\lVert Kx - d\rVert \le \sqrt{n}\,\sigma$ *and* $\lVert x\rVert \le \rho$ for a declared $\rho$, where $\rho$ can be estimated from the norm of a heavily regularised solution. This cannot run away because the norm bound caps the iterate, but it introduces a false-stop risk: if the true model norm exceeds $\rho$, the rule stops early and returns a biased, over-smoothed model whose residual is above the noise level. That trade is the same bias–variance trade as choosing $\alpha$.

**3.2** Disproved in general, true in the ideal case. With exact data and exact arithmetic the CG iterate minimises the error over the Krylov space, which is nested, so the error is monotone by construction. In floating point and with exact data the demo's matrix-free CG reached an error of 0.5447 at iteration 6 and 0.9998 by iteration 100: monotone in exact arithmetic, non-monotone in floating point.

**3.3** Early stopping with $k$ iterations filters the spectrum with a smooth polynomial; Tikhonov with $\alpha$ filters with $\lambda_i/(\lambda_i+\alpha)$. A polynomial filter with $k$ factors can approximate the Tikhonov filter over a finite spectral range, so at equal model error the two are close; the demo's oracle-stopped CG reached errors of $4.6\times10^{-1}$ to $6.1\times10^{-1}$ at residual ratios near 1.0, and the lesson's Tikhonov comparison (lesson 18-03-02) showed an oracle $\alpha$ with a slightly smaller error at the same residual. The measured conclusion is that neither dominates and both need a declared rule to pick the parameter.
