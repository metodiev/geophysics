# Solutions — Convergence Diagnosis and Local-Minimum Traps

**1.1** $\lambda_{\min}(\nabla^{2}f) > 0$ at the stationary point, so the smallest eigenvalue of the Hessian at the accepted point must be computed; $\lVert\nabla f\rVert \approx 0$ only proves stationarity.

**1.2** $\lvert\Delta\rvert = \text{tol}/\lambda$: along the steep direction $\lambda = 3.4180$, $\Delta = 10^{-3}/3.4180 = 2.926\times10^{-4}$ km $= 0.29$ m; along the flat direction $\lambda = 1.1953$, $\Delta = 10^{-3}/1.1953 = 8.37\times10^{-4}$ km $= 0.84$ m.

**1.3** $J^{\mathsf T}J$ is positive semidefinite by construction, so its eigenvalue test always returns "minimum" (or "flat"), and it cannot detect the negative curvature that the residual term $\sum_i r_i\nabla^{2}r_i$ contributes. It can still certify that a Gauss–Newton step is a descent direction.

**2.1** Central differences have a truncation error $\tfrac{h^{2}}{6}f'''$ and a roundoff error $\varepsilon\lvert f\rvert/h$ with $\varepsilon \approx 2.2\times10^{-16}$. At $h = 10^{-6}$ these are $\sim 10^{-12}$ and $\sim 10^{-10}$ — roundoff dominated, matching the measured $1.5\times10^{-10}$. At $h = 10^{-3}$ truncation $\sim 10^{-6}$ dominates; at $h = 10^{-8}$ roundoff $\sim 10^{-8}$ dominates, and the total is forty times worse than at $h = 10^{-6}$.

**2.2** $H C = \begin{pmatrix}3.3965 & 0.2174\\ 0.2174 & 1.2167\end{pmatrix}\begin{pmatrix}0.2978 & -0.0532\\ -0.0532 & 0.8314\end{pmatrix}$. Entry (1,1): $3.3965(0.2978) + 0.2174(-0.0532) = 1.0115 - 0.0116 = 1.000$. Entry (1,2): $3.3965(-0.0532) + 0.2174(0.8314) = -0.1807 + 0.1807 = 0.000$. Entry (2,2): $0.2174(-0.0532) + 1.2167(0.8314) = -0.0116 + 1.0115 = 1.000$. Correlation: $-0.0532/\sqrt{0.2978\times0.8314} = -0.0532/0.4976 = -0.1069$, matching the printed value.

**2.3** Counts: $1813/5 = 363$. Spreads: $0.294/0.011 = 26.7$. The volume grows far faster than the linear extent because the accepted set grows in two dimensions (and in general $n$), so a 27-fold linear growth is a 363-fold volume growth at $n \approx 2.1$; the exponent $\ln 363/\ln 26.7 = 5.89/3.28 = 1.80$ is consistent with a two-dimensional set whose shape is not self-similar.

**3.1** Objective and evaluation count (from the optimiser's bookkeeping; failure mode is that the count omits the cost of building the Jacobian). Termination message (free; failure mode is that every failure and every success reports "convergence"). $\lVert\nabla f\rVert$ at the accepted point (from one gradient evaluation; failure mode is a tolerance that is loose relative to the curvature). $\lambda_{\min}(H)$ (from an analytic, Gauss–Newton, or finite-difference Hessian; failure mode is that a finite-difference Hessian's sign is noise-dominated when the gradient is at the noise floor). Stopping tolerances and the permitted displacement $\text{tol}/\lambda_{\min}$ (arithmetic; failure mode is a missing units conversion). Condition number and correlation (from $H$ or $H^{-1}$; failure mode is quoting them as algorithm uncertainty). Multi-start best value (costs its budget; failure mode is an unresolvable $p$, so the best of $k$ is not evidence of globality). Near-equivalent set at a declared tolerance (uniform sampling or an ensemble; failure mode is a box that excludes the true model).

**3.2** The two numbers answer different questions. The 1-sigma widths are the square roots of the diagonal of $H^{-1}$, a *linearised* statement valid for small displacements, and they are large because the curvature is small. The accepted-set spread is the extent of the set where the *actual* objective is within 0.05 of its minimum, and it is smaller (0.29 km) because that tolerance is tighter than one standard error in the flat direction: one sigma corresponds to an objective change of $\tfrac12\lambda\sigma^{2} = 0.5\times1.1953\times(0.55)^2 = 0.181$ for the $x$ direction, i.e. 3.6 times the 0.05 tolerance, so the accepted set is smaller than the 1-sigma ellipse by roughly $\sqrt{0.05/0.181} = 0.53$ in that direction. Both are correct statements about their own tolerance.

**3.3** It is a result, and a useful one. The measured eigenvalues at the flat outer corner were $(0,0)$: the objective is locally constant there, so the point is a genuine stationary point of the search box and no second-order test can classify it. What would be an error is reporting it as a minimum; the demo's loose-$f_{\text{tol}}$ run did exactly that internally, and only the printed eigenvalues exposed it. A saddle or flat point is also informative about the model: it is a place where two parameters trade off exactly, which is the same degeneracy the accepted-set table quantifies at $\text{tol} = 0.05$, where the set spreads over hundreds of metres without the objective changing by more than 0.05.
