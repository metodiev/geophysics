# Exercises — 17-06-05 Multi-Criteria Decision Analysis for Suitability Mapping

Attempt these before reading the
[solutions](./05-multicriteria-decision-solutions.md). The lesson is
[05 Multi-Criteria Decision Analysis](../05-multicriteria-decision.md). All models
are **SYNTHETIC**.

## ★ Foundational

**★1.** Normalise the values 2, 5 and 8 by (a) min–max and (b) rank, and state
which one is sensitive to a new datum of 100.

**★2.** A 3 × 3 judgement matrix has weights (0.6, 0.3, 0.1). Write the matrix
entries that make it exactly consistent.

**★3.** A weighted overlay uses weights (0.5, 0.3, 0.2). An alternative scores
normalised values (1.0, 0.0, 0.0). Compute its score and state which single
criterion it is winning.

## ★★ Applied

**★★4.** A 4 × 4 judgement matrix has $\lambda_{\max} = 4.12$. Compute the
consistency index and the consistency ratio (RI = 0.90 for $n = 4$), and state
whether it is acceptable.

**★★5.** Four alternatives have weighted scores 0.72, 0.70, 0.68 and 0.40. A new
alternative is added and min–max normalisation is recomputed; state whether the
ranking of the original four can change, and why.

**★★6.** A study's best cell changes in 28 % of weight perturbations and its top-5 %
class overlaps by 0.94 on average. State what you would report and why the two
numbers differ so much.

## ★★★ Research-oriented

**★★★7.** Design a suitability study that reports a class, a rank range and a
weight-stability interval, and specify how you would present the result so that a
decision-maker can see how much of the conclusion is the data and how much is the
rule.

**★★★8.** Two criteria in a five-criterion overlay are correlated with $r = 0.85$.
Quantify the effect on the effective weights of the remaining criteria and state
the remedies available.
