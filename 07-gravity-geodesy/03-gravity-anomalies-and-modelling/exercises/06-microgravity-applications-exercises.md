# Exercises — 07-03-06 Microgravity for Cavities, Tunnels and Archaeology

Attempt these before reading the
[solutions](./06-microgravity-applications-solutions.md). The lesson is
[06 Microgravity](../06-microgravity-applications.md). All models are
**SYNTHETIC**; $1\ \mu\mathrm{Gal} = 10^{-8}\ \mathrm{m\,s^{-2}}$, and
$G = 6.67430\times10^{-11}\ \mathrm{m^{3}\,kg^{-1}\,s^{-2}}$.

## ★ Foundational

**★1.** Convert $25\ \mu$Gal to $\mathrm{m\,s^{-2}}$ and to mGal.

**★2.** Compute the on-axis anomaly of a $1.5\ \mathrm{m}$ radius air-filled
cavity ($\Delta\rho = -2000\ \mathrm{kg\,m^{-3}}$) whose centre is at
$4\ \mathrm{m}$ depth.

**★3.** State the half-width depth rule for a cavity modelled as a sphere and for a
tunnel modelled as a horizontal cylinder, and say why they differ.

## ★★ Applied

**★★4.** A modified tunnel profile fitting gave a residual peak of
$30\ \mu$Gal and a half-width of $6\ \mathrm{m}$. Compute the depth under the
cylinder rule, the line mass per metre of tunnel, and the tunnel radius assuming
$\Delta\rho = -2000\ \mathrm{kg\,m^{-3}}$.

**★★5.** A cavity has a $1\ \mathrm{m}$ radius under $4\ \mathrm{m}$ of rock. Using
the detectability relation, state whether a $1\ \mu$Gal noise level (a
repeat-reading precision, not the instrument resolution) makes detection possible,
and what density contrast is required if it does not.

**★★6.** Explain why an air-filled cavity and a water-filled cavity of the same
size and depth differ by exactly a factor two, and what this implies for the
inversion of a single anomaly.

## ★★★ Research-oriented

**★★★7.** A survey must distinguish a water-filled void at $3\ \mathrm{m}$ from an
air-filled void at a greater depth. Compute the depth at which the two would give
the same anomaly, and specify the station spacing and repeat protocol you would
need to break the degeneracy using the profile width instead of the amplitude.

**★★★8.** Using the noise-to-depth table in the lesson
($0.5$, $1.0$, $2.0\ \mu$Gal giving $0.07$, $0.15$, $0.31\ \mathrm{m}$ scatter),
estimate the depth uncertainty for a $4\ \mathrm{m}$ spacing and state which
assumption dominates the error in a real survey.
