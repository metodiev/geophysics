# Exercises — 07-04-02 Height Systems: Ellipsoidal, Orthometric, Dynamic and Geoid Models

Attempt these before reading the
[solutions](./02-height-systems-solutions.md). The lesson is
[02 Height Systems](../02-height-systems.md). Normal gravity is evaluated with
the standard Somigliana formula and WGS 84 defining constants; all levelling
lines, gravity values and geoid undulations are **SYNTHETIC**.

## ★ Foundational

**★1.** Evaluate $\gamma(0^{\circ})$, $\gamma(45^{\circ})$ and
$\gamma(90^{\circ})$ and give the polar-minus-equatorial difference in mGal and as
a percentage.

**★2.** Compute the geopotential number for a $200\ \mathrm{m}$ climb at constant
$g = 9.81\ \mathrm{m\,s^{-2}}$, with units shown at every step.

**★3.** State the four height systems in one line each, and say which one requires
the Earth's internal density structure.

## ★★ Applied

**★★4.** A station has $C = 1961.2\ \mathrm{m^{2}\,s^{-2}}$,
$\gamma(\varphi) = 9.8050\ \mathrm{m\,s^{-2}}$ and
$\gamma_{45^{\circ}} = 9.806198\ \mathrm{m\,s^{-2}}$. Compute the dynamic height
and the normal height, and the difference between them.

**★★5.** A line climbs $500\ \mathrm{m}$ with a $+20\ \mathrm{mGal}$ anomaly
confined to the climb. Estimate the error made by treating the plain sum of
levelling increments as the orthometric height, and state why the answer would be
zero for a uniform gravity offset.

**★★6.** A levelling loop of $40$ setups has a misclosure of $8\ \mathrm{mm}$.
Decide whether it is random or systematic, and state the test that settles it.

## ★★★ Research-oriented

**★★★7.** Design a levelling-plus-gravity procedure that determines orthometric
heights to $1\ \mathrm{cm}$ over a $100\ \mathrm{km}$ line, listing the error terms
and identifying the dominant one.

**★★★8.** A regional vertical datum is to be modernised: orthometric heights will
be replaced by a global frame in which heights are ellipsoidal plus a geoid model.
State the systematic changes in the numbers, the size of the change for a
mountainous country, and the calibration measurements that would keep the change
consistent.
