# --- Notes on optional / heavy dependencies ----------------------------------
# * GMT + PyGMT: PyGMT is a Python wrapper; it needs the GMT C library installed
#   by your package manager or conda. On conda, `conda install -c conda-forge pygmt`
#   installs both together, which is the least painful route.
#   On macOS with Homebrew, GMT and Ghostscript are BOTH required:
#       brew install gmt ghostscript
#   Ghostscript is not optional. GMT's `psconvert` module shells out to `gs`, so
#   without it every `Figure.savefig()` fails with
#       pygmt.exceptions.GMTCLibError:
#         Module 'psconvert' failed with status code 79:
#         psconvert [ERROR]: Cannot execute Ghostscript (gs).
#   PostScript output still works; only raster/PDF conversion needs Ghostscript.
# * GPU support for torch requires a platform-specific index URL; install it
#   separately following the official PyTorch instructions rather than from
#   this file.
# * Some packages lag behind the newest CPython releases. If you are on a very
#   new Python version (for example 3.14) and a wheel is unavailable, use the
#   conda environment in environment.yml, which can fall back to older but
#   fully supported interpreter versions.
#
