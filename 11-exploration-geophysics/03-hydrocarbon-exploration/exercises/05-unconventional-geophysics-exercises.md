# Exercises — 11-03-05 Geophysics for Unconventional Reservoirs

Attempt these before reading the
[solutions](./05-unconventional-geophysics-solutions.md). The lesson is
[05 Geophysics for Unconventional Reservoirs](../05-unconventional-geophysics.md).
All models are **SYNTHETIC** teaching values.

## ★ Foundational

**★1.** A shale has $v_p = 3.80\ \mathrm{km\,s^{-1}}$,
$v_s = 2.05\ \mathrm{km\,s^{-1}}$, $\rho = 2480\ \mathrm{kg\,m^{-3}}$. Compute
Young's modulus and Poisson's ratio, showing the numerator and denominator
separately.

**★2.** Compute both brittleness indices of ★1 using the lesson's endpoints
($E$: 15.4–80.2 GPa, $\nu$: 0.206–0.287) and state what happens when an index
falls outside $[0,1]$.

**★3.** For $v_s = 2.90\ \mathrm{km\,s^{-1}}$ and $\gamma = 0.03$, compute
$v_{\text{fast}}$ and the shear-wave splitting time over an 80 m interval, both
exactly and with the first-order form, and report the relative difference.

## ★★ Applied

**★★4.** An event has $M_0 = 4\times10^{12}$ N m, $v_s = 3.0\
\mathrm{km\,s^{-1}}$, $\mu = 20$ GPa. Compute $M_w$, the rupture radius for an
assumed $\Delta\sigma = 2$ MPa, and the mean slip. State which of the four
quantities is assumed rather than measured.

**★★5.** Using the lesson's detection table, compare the detection radius of a
$M_w = 1$ event and a $M_w = 2$ event, and explain the ratio physically in one
sentence. Then state the consequence for a catalogue assembled at a fixed
threshold.

**★★6.** A monitoring network has 12 stations at 1.0–3.0 km range and 2 ms pick
errors on a $v = 3.0\ \mathrm{km\,s^{-1}}$ model. Estimate the *distance* error
implied by one pick, and state why the actual location error can be ten times
larger.

## ★★★ Research-oriented

**★★★7.** Design a monitoring network for a 3 km deep, 2 km by 2 km reservoir
with a target $M_c = 0$ throughout the volume, using the lesson's detection
model. State the sensor count, the geometry, the assumed noise floor, and the
one thing your design cannot deliver. Justify the geometry with numbers.

**★★★8.** Derive the Coulomb failure condition for slip on a cohesionless
fracture under pore pressure, plot (analytically) the required pressure as a
function of $\tau/\sigma_n$, and state the stress ratio at which the fracture
is already critical for $\mu_f = 0.6$. Explain why this quantity cannot be
measured from the surface.
