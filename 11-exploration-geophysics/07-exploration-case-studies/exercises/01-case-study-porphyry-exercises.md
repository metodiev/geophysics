# Exercises — 11-07-01 Case Study: Porphyry Copper District

Attempt these before reading the
[solutions](./01-case-study-porphyry-solutions.md). The lesson is
[01 Case Study: Porphyry Copper District](../01-case-study-porphyry.md).
All models are **SYNTHETIC** argument archetypes: no real deposit, district or
hole is used, and no site-specific number is quoted.

## ★ Foundational

**★1.** An indicator has $\mathrm{TPR} = 0.65$ and $\mathrm{FPR} = 0.20$.
Compute its likelihood ratio, and the posterior probability for base rates of
$0.01$ and $0.10$.

**★2.** For the posterior of ★1 at $p = 0.01$, compute the expected number of
drilled anomalies per discovery.

**★3.** A magnetic profile is modelled as a vertical dipole with half-width
$x_{1/2} = 180\ \mathrm{m}$. Compute the depth, and the depth you would obtain
if the source were a two-dimensional cylinder instead.

## ★★ Applied

**★★4.** Three indicators each have $\mathrm{TPR}/\mathrm{FPR} = 0.7/0.2$ and the
base rate is $0.02$. Compute the posterior for $n = 1, 2, 3$ assuming
independence, and then for the case where two of them share a cause and are
counted as one. State the ratio between the largest and the smallest $n = 3$
value.

**★★5.** A hole costs $C$ and a discovery is worth $50C$. Compute the
break-even posterior and decide whether to drill at posteriors of $0.01$, $0.03$
and $0.10$.

**★★6.** An interpreter reports a magnetic depth of 400 m from a profile whose
half-width is 300 m. Using the two archetype shapes, compute the two depths
consistent with that half-width and state which the interpreter must have
assumed.

## ★★★ Research-oriented

**★★★7.** Write a one-page targeting statement for a covered porphyry target in
a magmatic arc, with: the target, the evidence suite, the claimed link, the
alternatives for each indicator, the base rate you would use and why, and the
decision rule. It must quote no site-specific number and must be falsifiable.

**★★★8.** The lesson's shared-risk computation uses a single correlation
parameter. Design a better model: name the geological processes that couple the
indicators, state which pairs you would model as conditionally dependent, and
describe how you would estimate the dependence from data you could actually
obtain. State how the answer would change a drill decision.
