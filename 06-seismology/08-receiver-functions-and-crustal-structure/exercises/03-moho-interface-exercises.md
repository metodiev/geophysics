# Exercises — 06-08-03 Moho Discontinuity Depth and Sharpness

Attempt before the [solutions](./03-moho-interface-solutions.md). Lesson:
[03 Moho Interface](../03-moho-interface.md). All models **SYNTHETIC**.

## ★ Foundational

**★1.** Convert a Ps delay of $4.10\ \mathrm{s}$ at
$p = 0.060\ \mathrm{s\,km^{-1}}$ to a depth, given $v_p = 6.30\
\mathrm{km\,s^{-1}}$ and $k = 1.72$.

**★2.** Compute the vertical slownesses and state the unit of each.

## ★★ Applied

**★★3.** Derive $\delta H = \delta p\,Hp(q_p^{-1}-q_s^{-1})/(q_s-q_p)$ and
evaluate it for a $\delta p = +0.008\ \mathrm{s\,km^{-1}}$ error with
$H = 35\ \mathrm{km}$, $p = 0.055\ \mathrm{s\,km^{-1}}$, $v_p = 6.2$,
$k = 1.72$.

**★★4.** A conversion amplitude is $0.62$ of the sharp-interface value at
$f = 0.25\ \mathrm{Hz}$, $q_s = 0.27\ \mathrm{s\,km^{-1}}$. Find the transition
width using the first sinc root.

**★★5.** A peak appears at $13.5\ \mathrm{s}$ with a *negative* moveout slope.
Explain why it is not a deep Moho and compute its moveout slope for the model
$H = 30\ \mathrm{km}$, $v_p = 6.2$, $k = 1.72$.

## ★★★ Research-oriented

**★★★6.** Design a bandwidth study for a $4\ \mathrm{km}$ transition: compute
the amplitude factor at $0.2$, $0.5$, $1.0$ and $2.0\ \mathrm{Hz}$ and state at
which frequencies the interface would be reported as sharp. State the frequency
you would choose and why.

**★★★7.** Argue, with numbers, why a $\pm5\%$ error in $k$ is a larger threat to
a Moho map than a $\pm10\%$ error in the reference slowness $p$.
