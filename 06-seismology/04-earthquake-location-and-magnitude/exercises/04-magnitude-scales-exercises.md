# Exercises — 06-04-04 Magnitude Scales: Local, Body, Surface, Duration, Moment

Attempt these before reading the
[solutions](./04-magnitude-scales-solutions.md). The lesson is
[04 Magnitude Scales](../04-magnitude-scales.md). All models are **SYNTHETIC**
teaching values.

## ★ Foundational

**★1.** Compute $M_w$ for $M_0 = 3.0\times10^{16}\ \mathrm{N\,m}$ and for
$M_0 = 10^{19}\ \mathrm{N\,m}$.

**★2.** Using the demonstration's path factor
$4\pi\rho\beta^{3}R = 1.4547\times10^{20}$ and $a = 0.6325$, compute the spectral
plateau for $M_0 = 10^{19}\ \mathrm{N\,m}$.

**★3.** Given $f_c = 0.6\ \mathrm{Hz}$ at $M_0 = 10^{15}\ \mathrm{N\,m}$, compute
$f_c$ for $M_0 = 10^{20}\ \mathrm{N\,m}$.

## ★★ Applied

**★★4.** Derive the slopes $\mathrm{d}M/\mathrm{d}M_w = 3/2$ and $1/2$ for a
fixed-band scale, and state the condition on $f_b/f_c$ for each.

**★★5.** Compute the 1 Hz band amplitude for the $M_0 = 10^{20}\ \mathrm{N\,m}$
event (use the plateau from ★2's scaling, $f_c$ from ★3, attenuation factor
$\exp(-\pi f t^{*}/Q)$ with $t^{*} = 28.57\ \mathrm{s}$ and $Q = 400$), and
compare with the printed $5.804\times10^{1}\ \mathrm{\mu m}$.

**★★6.** Using the printed values $m_l = 1.64$ at $M_w = 1.93$ and $m_l = 3.37$
at $M_w = 3.27$, compute the secant slope and compare with the least-squares
value of 1.299 for that third of the range.

## ★★★ Research-oriented

**★★★7.** Specify a test, using only a catalogue and a measured spectrum, that
would distinguish "the $M_s$ scale is saturated" from "the source is not
self-similar", and state the observation that would decide it.

**★★★8.** The demonstration's additive constants are internal. Design the
experiment that would determine them for a real network, list the inputs it
requires, and state how you would report the resulting uncertainty in a
magnitude.
