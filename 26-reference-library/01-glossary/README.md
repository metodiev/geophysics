# Module 26-01 — Glossary of Geophysical Terms

**Stages:** beginner → research · **Prerequisites:** none (lookup resource)

A four-page glossary of the vocabulary used across the repository. It is
organised the only way a glossary can be: alphabetically, in four letter ranges,
so that a word you met in a lesson can be resolved in a few seconds. Nothing
here is meant to be read in sequence.

The glossary exists because geophysics reuses an unusually small set of words
for an unusually large set of meanings. *Anomaly* means a reduction in gravity
and a residual in magnetics. *Fold* is a structure and a multiplicity. *Phase*
is an angle, a mineral assemblage and a stage of a project. *Impedance* is
$\rho v$ in seismology, a complex voltage-to-current ratio in electronics, and a
tensor in magnetotellurics. Rather than choosing one meaning silently, each
entry lists the meanings it has, and says how to tell them apart — usually by
the units.

## How this glossary is written

| Rule | Why |
|---|---|
| One to three sentences per term | A glossary resolves a word; a lesson teaches it |
| Units given on every quantitative entry | Unit checks are the fastest disambiguation |
| Overload flagged explicitly | Silently choosing a meaning is the commonest terminology error |
| Numbers marked *typical* or *nominal* | A glossary value is not a measurement and must not be cited as one |
| No copyrighted text | Definitions are summarised in this repository's own words |

Every lesson ends with a "where it is taught properly" table pointing at the
folder that treats the topic in depth, so that a glossary lookup leads on to the
real treatment rather than stopping here.

## Mastery checkpoint

There is no checkpoint. The skill this module supports is **looking the word up
instead of guessing it**, and in particular noticing when a paper's "anomaly",
"phase" or "impedance" is not the one you assumed.

## Common pitfalls across this module

1. **Subfield collisions.** *Resistivity* and *density* are both $\rho$;
   *wavenumber*, *permeability* and *thermal conductivity* are all $k$.
2. **Magnitude scales.** Writing "magnitude 6.5" without the scale is not a
   complete statement.
3. **Citing glossary numbers.** Typical values are for orientation; a specific
   site needs a specific measurement.
4. **Reduction without a reference.** "The anomaly" is meaningless without
   stating what was removed.
5. **Datums.** Coordinates and heights are ambiguous to tens of metres without a
   stated datum and frame.
