## ★1 — Ekman and magnetic Prandtl numbers

$$E = \frac{\nu}{\Omega L^2} = \frac{10^{-6}}{7.292\times10^{-5}\times
(3.48\times10^6)^2} = \frac{10^{-6}}{8.83\times10^{8}} = 1.13\times10^{-15}.$$

$$Pm = \frac{\nu}{\eta} = \frac{10^{-6}}{0.7958} = 1.26\times10^{-6}.$$

$E$ compares the viscous diffusion time to the rotation period: it sets the
thickness of the viscous boundary layer, $\sqrt{\nu/\Omega} = 3.7$ m in a
3480-km body. $Pm$ compares momentum diffusion to magnetic diffusion: it sets how
much finer the velocity structures are than the field structures.

## ★2 — The two terms of the induction equation

$$\frac{\partial\mathbf{B}}{\partial t}
= \underbrace{\nabla\times(\mathbf{u}\times\mathbf{B})}_{\text{advection:
creates field}}
+ \underbrace{\eta\nabla^2\mathbf{B}}_{\text{diffusion: destroys it}} .$$

Scaling each term by $B/L^2$ gives the ratio

$$\frac{|\nabla\times(\mathbf{u}\times\mathbf{B})|}{|\eta\nabla^2\mathbf{B}|}
\sim \frac{UB/L}{\eta B/L^2} = \frac{UL}{\eta} = Rm .$$

A dynamo requires $Rm \gtrsim O(10)$; the core's value is $2\times10^3$.

## ★3 — Two-mode dynamo

$$D = \frac{\alpha\omega}{\kappa^2} = \frac{1.5\times1.5}{1} = 2.25,$$

$$\sigma = -\kappa + \sqrt{\alpha\omega} = -1 + 1.5 = +0.5\ \text{per unit time}
\quad(\text{growth}).$$

At saturation with $B_{\text{sat}} = 1$,
$A = \sqrt{D - 1} = \sqrt{1.25} = 1.118$, where $A^2 = P^2 + T^2$.

---

## ★★4 — Growth rates and the saturated ratio

Write the linear system as $\dot{\mathbf{y}} = \mathsf{M}\mathbf{y}$ with
$\mathsf{M} = \begin{pmatrix}-\kappa & \alpha\\ \omega & -\kappa\end{pmatrix}$.
The eigenvalues satisfy

$$(-\kappa-\sigma)^2 - \alpha\omega = 0
\;\Longrightarrow\;
\sigma = -\kappa \pm \sqrt{\alpha\omega},$$

so onset ($\sigma = 0$) requires $\alpha\omega = \kappa^2$, i.e. $D = 1$.

At saturation both derivatives vanish. From $\dot{P} = 0$,
$P = (\alpha/\kappa)T$; from $\dot{T} = 0$, $T = (\omega/\kappa)P$. Solving
together with $\alpha = \alpha_0/(1 + A^2)$ gives $A^2 = D - 1$ and

$$\frac{T}{P} = \frac{\omega}{\kappa}.$$

The state is **steady** because both amplitudes are real, positive constants with
a fixed ratio. An oscillatory solution requires complex eigenvalues, which the
matrix (with real $\alpha$, $\omega$, $\kappa$) has only when
$\alpha\omega < 0$ — impossible for a growth-mode dynamo. Reversals need a
different nonlinearity, which is why the three-mode truncation exists.

## ★★5 — Grid requirement

$$\sqrt{\frac{\eta}{\nu}} = \frac{1}{\sqrt{Pm}} =
\frac{1}{\sqrt{10^{-4}}} = 100 .$$

Resolving both diffusion lengths in three dimensions needs of order
$100^3 = 10^6$ points. For $Pm = 1$ the ratio is 1 and a single scale suffices —
which is why every published dynamo runs near $Pm = 1$ rather than at the core's
$10^{-6}$, where the requirement would be $892^3 = 7.1\times10^8$ points.

The practical implication is **not** merely cost: a dynamo's field is generated by
the smallest scales of the flow, so a grid that cannot resolve the velocity
structures cannot reproduce the $\alpha$-effect at all, however the run is
tuned.

## ★★6 — Elsasser number

$$\Lambda = \frac{B^2}{\mu_0\rho\eta\Omega}
= \frac{(2\times10^{-3})^2}{1.2566\times10^{-6}\times1.1\times10^4
\times0.7958\times7.292\times10^{-5}} = 4.99 .$$

$\Lambda \approx 5 > 1$: the Lorentz force is a few times the Coriolis force, so
the field is in the magnetostrophic regime the Earth's core is believed to occupy.

To obtain $\Lambda = 0.3$ at fixed $\rho$, $\eta$ and $\Omega$ requires
$B^2$ smaller by a factor $16.6$, i.e. $B = 2/\sqrt{16.6} = 0.49\ \mathrm{mT}$.
Equivalently, since $\Lambda \propto B^2/\eta$, a simulation with fifty times the
core's $\eta$ would need $\sqrt{50} = 7.1$ times the core's $B$ to reach the same
$\Lambda$ — which is the sense in which a high-diffusivity simulation must be run
at a field strength that is not the core's.

## ★★★7 — Extrapolating $B \propto Pm^{1/2}$

At $Pm = 1$ write $B = B_1$; then $B(Pm) = B_1 Pm^{1/2}$. Extrapolating from
$Pm = 1$ to $Pm = 10^{-6}$:

$$\frac{B(10^{-6})}{B(1)} = (10^{-6})^{1/2} = 10^{-3}.$$

A $\pm0.1$ change in the exponent gives

$$(10^{-6})^{0.4} = 10^{-2.4} = 3.98\times10^{-3}, \qquad
(10^{-6})^{0.6} = 10^{-3.6} = 2.51\times10^{-4},$$

a range spanning a factor of **16** for a 20% change in the fitted exponent.

The honest output is the range: the exponent is fitted to a suite of runs whose
$Ra$ and $E$ also vary, so it is not a property of $Pm$ alone but of the
parameter path along which the extrapolation is taken. Quoting
$10^{-3}$ would hide a factor of 16.

## ★★★8 — Verification suite for a new dynamo code

| Test | Reference | Tolerance |
|---|---|---|
| Free decay of a dipole in a conducting sphere with an insulating exterior | the eigenvalue condition $(2l+1)j_l(x) = x j_{l+1}(x)$; slowest $x = \pi$ | $10^{-6}$ relative in $\tau$ |
| Two-mode $\alpha$-$\Omega$ growth rate | $\sigma = -\kappa + \sqrt{\alpha\omega}$, measured from the code's own time series | $10^{-4}$ relative |
| Saturation amplitude with quenching | $A = \sqrt{D-1}$ | $10^{-3}$ relative |
| Cross-code benchmark | a fixed parameter set run by an independent code, comparing mean field energy, ohmic dissipation, Nusselt number and drift rate | a few per cent |
| $\nabla\cdot\mathbf{B}$ | identically zero | machine precision |
| Energy budget | ohmic + viscous dissipation equals the buoyancy power supply | $10^{-3}$ relative |
| Lorentz-term sign | run with the Lorentz force reversed: the dipole must collapse | qualitative, and decisive |

The last row is the discriminating test for a sign error: a code with the Lorentz
force the wrong way round still satisfies the free-decay and linear-growth tests
(because they do not involve the Lorentz force), but it cannot maintain a
saturated dipole — the field either grows without bound or decays to the
kinematic level. Any verification suite that omits a saturation test will miss
this class of bug.
