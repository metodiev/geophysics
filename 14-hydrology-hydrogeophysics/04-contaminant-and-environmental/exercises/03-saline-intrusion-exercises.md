# Exercises — 14-04-03 Seawater Intrusion and Coastal Aquifer Monitoring

Attempt before the [solutions](./03-saline-intrusion-solutions.md). Lesson:
[03 Seawater Intrusion and Coastal Aquifer Monitoring](../03-saline-intrusion.md).
All models **SYNTHETIC**. Standard densities: fresh water
$1000\ \mathrm{kg\,m^{-3}}$, seawater $1025\ \mathrm{kg\,m^{-3}}$ unless stated.

Use $\sigma_f = 0.050\ \mathrm{S\,m^{-1}}$, $\sigma_s = 4.00\
\mathrm{S\,m^{-1}}$ and linear mixing of conductivities unless stated.

## ★ Foundational

**★1.** A synthetic coast has a saline end member of $1027\
\mathrm{kg\,m^{-3}}$. Compute the Ghyben–Herzberg ratio and the interface depth
for a head of $1.50\ \mathrm{m}$. Compare with the value for a saline density of
$1025\ \mathrm{kg\,m^{-3}}$ and explain the direction of the difference.

**★2.** For a head of $1.50\ \mathrm{m}$ and a fall of $0.30\ \mathrm{m}$, compute
the interface rise and the fresh-water volume change per unit area for
$\phi = 0.25$.

**★3.** With $\phi = 0.35$, $a = 1$, $m = 1.8$, compute the bulk resistivity at
$c = 0$ and $c = 0.20$, and the fraction of the log contrast at $c = 0.20$.

## ★★ Applied

**★★4.** A transition zone is described by
$c(z) = 0.5\operatorname{erfc}((z_i-z)/(2\sigma))$ with $z_i = 30\
\mathrm{m}$ and $\sigma = 5\ \mathrm{m}$. Compute the 10–90% width and state it
as a fraction of the interface depth.

**★★5.** A $1\ \mathrm{m}$ rise of the interface must be detected. Using the
lesson's two-layer results, state at which spacings relative to the interface
depth you would place the array and why the smallest spacings are excluded.
Extend the argument to a $0.2\ \mathrm{m}$ rise and state what changes.

**★★6.** With $\sigma_\text{clay} = 0.02\ \mathrm{S\,m^{-1}}$,
$\phi = 0.30$ and $m = 2$, compute the equivalent saline fraction for saline end
members of $4.0$, $0.8$ and $0.5\ \mathrm{S\,m^{-1}}$, and state the operational
consequence.

## ★★★ Research-oriented

**★★★7.** Design a monitoring programme for a coastal well field that must
detect a $0.5\ \mathrm{m}$ interface rise within one season. **(a)** Choose the
methods and justify each from the two-fluid physics. **(b)** State the
observable and the detection threshold for each. **(c)** State the alternative
hypothesis each method cannot exclude on its own and how the combination
addresses it.

**★★★8.** The Ghyben–Herzberg relation assumes a static sharp interface.
**(a)** State the two assumptions that fail first in a pumped aquifer and the
phenomenon each hides. **(b)** Explain with an order-of-magnitude argument why
upconing beneath a well with a drawdown of a few metres can be more damaging
than a regional head decline of the same size. **(c)** State the observation that
would distinguish upconing from regional intrusion.
