# Exercises — 22-01-05 Licensing, Citation and Software Credit (CITATION.cff)

Attempt these before reading the
[solutions](./05-licensing-and-citation-solutions.md). The lesson is
[05 Licensing, Citation and Software Credit](../05-licensing-and-citation.md).
Licence cases are the **ILLUSTRATIVE** teaching model of the lesson and the
version list is generated by `code/licensing_and_citation_demo.py`. This is not
legal advice: verify any conclusion against the licence texts and the SPDX
compatibility notes.

## ★ Foundational

**★1.** Classify each licence as permissive, weak copyleft, strong copyleft or
network copyleft, and state the forced licence of the combined work:
(a) MIT, (b) MPL-2.0, (c) LGPL-3.0, (d) GPL-3.0, (e) AGPL-3.0. Then give the
forced combined licence for the pairs MIT + GPL-3.0, LGPL-3.0 + GPL-3.0 and
GPL-3.0 + AGPL-3.0.

**★2.** Write a complete `CITATION.cff` for a package called *Tidal strain-rate
toolkit*, version `1.1.3`, MIT-licensed, with two authors (Anna Rossi, ORCID
`0000-0000-0000-0000`; and Bila Nkosi, no ORCID) and a software DOI
`10.0000/example.doi`. State which fields are required by the format and which
are optional but recommended.

**★3.** Using the demonstration's release list
`1.0.0, 1.0.3, 1.1.0, 1.1.3, 1.2.0, 1.2.3, 1.3.0, 1.3.3, 2.0.0, …`, count the
admissible releases for `~2.1` and for `>=1.3,<2.1`, and state which of the three
constraints in the lesson (`^1.2`, `~1.2`, `>=2.0,<3`) is the strictest.

## ★★ Applied

**★★4.** The demonstration's citation model is
$\text{cum}(m) = c_0\,(e^{rm} - 1)/(e^{r} - 1)$ with $c_0 = 8$ citations per year
in the first year and $r = 0.35$ per year.

(a) Verify the printed crossing year for a target of 25 cumulative citations by
solving the equation by hand. (b) Compute the crossing year for a target of 200.
(c) State what would happen to all three crossing years if $r$ were 0.20 instead,
and give the new year for the target of 25.

**★★5.** Audit this dependency list for a package you intend to publish in a
container image:

| Dependency | Licence | Used for |
|---|---|---|
| `numpy` | BSD-3-Clause | numerics in the published analysis |
| `some-gpl-tool` | GPL-3.0 | a one-off calibration figure, not in the published analysis |
| `libfoo` | LGPL-3.0 | linked into the analysis binary |
| `chartlib` | MPL-2.0 | plotting in the published notebooks |

State (a) which dependencies are distributed by the container, (b) the forced
combined licence, and (c) one change that would remove the copyleft obligation
entirely.

**★★6.** Write the one-sentence software-availability statement for the release of
★★2, and list the three facts about the environment that must accompany it for a
reader to reproduce a figure.

## ★★★ Research-oriented

**★★★7.** Design a measurement of the credit a software package receives: state
the population of citing works, how you would identify a citation to the software
as opposed to its method paper, the two confounders, and what the DOI does and
does not guarantee. A specification that could not be executed is a failed
answer.

**★★★8.** A group claims "our toolkit is cited 137 times, so it is correct".
Design a study that would test whether citation count is associated with
correctness, state the correctness measure you would use, and name the two
biases (field, age) the design must control. State the conclusion you could and
could not draw from a positive result.

**★★★9.** A group must publish a container image that includes a GPL-3.0 tool.
Propose three policies (remove, replace, or comply), state the cost and the
scientific consequence of each, and state the facts a data management plan would
have to record for the compliant option.
