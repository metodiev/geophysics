# Module 00-01 — Study Roadmap

**Stage:** all stages · **Prerequisites:** none

This module defines the *method* of the curriculum: how to study geophysics so
that you end up able to do it, not merely able to recall it. Read it once
properly now, then return to it at each stage transition as a checklist.

## Learning objectives

By the end of this module you will be able to:

1. Explain why geophysics is best learned as a chain of *inference* rather than
   as a list of methods to memorise.
2. Name the six learning stages and state, for each, the entry requirement and
   the mastery checkpoint.
3. Place yourself on that ladder using the diagnostic self-assessment, and
   choose a defensible entry point.
4. Apply deliberate-practice and spaced-repetition habits to technical material
   that requires derivation and computation, not just reading.
5. Describe the research milestones that separate a competent practitioner
   from an independent investigator.

## The core study loop

For every lesson in this repository, use the same five-step loop. It is short,
and skipping steps is why people finish a curriculum without gaining the skill.

```text
1. SKIM      Read headings and the summary first. Form a question before reading.
2. DERIVE    Redo every derivation yourself, on paper, without looking.
3. COMPUTE   Run the Python demonstration. Break it deliberately; predict the failure.
4. SOLVE     Attempt exercises at your target difficulty before reading solutions.
5. EXPLAIN   Write a two-paragraph summary from memory: what, and why it matters.
```

**Steps 2 and 3 are the ones people skip.** Reading a derivation is not learning
a derivation; running someone else's code is not learning to compute. If you
only have thirty minutes, do step 2 or step 3 badly rather than doing step 1
well.

## Mastery checkpoint

You have completed this module when you can, without notes:

- [ ] Draw the inference chain (property contrast → field response → measurement
      → inversion → model + uncertainty) and give one concrete example per link.
- [ ] State your own current stage and the next checkpoint you are aiming at.
- [ ] Explain why "I read all the lessons" is not evidence of mastery.
