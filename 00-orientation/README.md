## The one-paragraph summary

Geophysics infers the structure and state of the Earth's interior from
**measurements made at a distance**. Almost every result in this curriculum
follows the same logical chain:

> a physical property contrast in the subsurface
> → produces a measurable field or wave response
> → which we record with an instrument
> → and must then **invert**, critically, into a model,
> → whose uncertainty we must state honestly.

Every lesson you will read is some elaboration of one link in that chain. When
you get lost in a derivation, come back to this sentence and ask which link
you are currently working on.

## Learning stages

This curriculum is organised around six stages, each with an explicit mastery
checkpoint rather than a vague sense of "having covered" a topic:

**Beginner** → **Intermediate** → **Advanced** → **Graduate** → **Doctoral** → **Research professional**

The full definitions, entry requirements, and checkpoints are in
[six stages](./01-study-roadmap/02-six-stages.md).
